## 一、《脉经》MJ（卷一 脉法总论 + 脉象提纲 + 脉证对应）

> 底本为明万历吴勉学本，卷一目录列"脉形状指下秘決第一（二十四種）"等篇。正文行间有双行小注，转写时以「（）」表示原书小注。

## MJ-P009｜卷一·目录（脉形状指下秘決第一 二十四種）

```
從橫逆順伏匿脉第十一
辯災怪恐怖雜脉第十二
遲疾短長雜脉第十三
平人得病所起脉第十四
診病將差難已脉第十五
脉形狀指下秘決第一　（二十四種）
浮脉　舉之有餘按之不足（浮於手下）
芤脉　浮大而軟按之中央空兩邊實（一曰手下無兩傍有）
洪脉　極大在指下（一曰浮而大）
滑脉　往來前却流利展轉替替然與數相似（一曰浮中如有力）
數脉　去來促急（一曰一息六七至）
```
> 备注：本页为卷一目录，列脉象提纲诸篇目，可见"脉形状指下秘決第一"统二十四脉，是全书脉象定义总纲。

## MJ-P010｜卷一·脉形状指下秘決第一（续）

```
（促）脉　來去數時一止復來（一曰息六七至名促）
弦脉　舉之無有按之如弓弦狀（一曰如張弓弦按之不移又曰浮緊為弦）
緊脉　數如切繩狀（一曰如轉索之無常）
沈脉　舉之不足按之有余（一曰重按之乃得）
伏脉　極重指按之著骨乃得（一曰手下裁動一曰按之不足舉之有余一曰關上沈不出名曰伏）
革脉　有似沈伏實大而長微弦（千金翼革以為牢又曰浮）
實脉　大而長微強按之隱指愊愊然（一曰沈浮皆得）
微脉　極細而軟或欲絕若有若無（一曰小也一曰手下快一曰浮而薄一曰按之如欲盡）
濇脉　細而遲往來難且散或一止復來（一曰浮而短一曰短而止或曰散也）
細脉　小大於微常有但細耳
軟脉　極軟而浮細（軟一作濡　呂氏曰濡者如帛在水中輕手相得按之無有）
弱脉　極軟而沈細按之欲絕指下（一曰按之無有舉之有余一曰細小而軟）
```
> 备注：本页为脉象定义主体：弦紧沉伏革实微涩细软弱诸脉的指下形态，是"看脉象断病因"的形态依据（如浮紧为弦、革似沉伏实大长）。

## MJ-P011｜卷一·脉形状指下秘決第一（续·Finished）

```
虛脉　遲大而軟按之不足隱指豁豁然空
散脉　大而散散者氣實血虛有表無裏
緩脉　去來亦遲小駃於遲（一曰浮大而軟陰與陽同等）
遲脉　呼吸三至去來極遲（一曰舉之不足按之盡牢一曰按之無有舉之如牢）
結脉　往來緩時一止復來（按之來緩時一止者名結陽初來動止更來小數不了了結者名結陰）
代脉　來數中止不能自還因而復動脉結者生代者死
動脉　見於關上無頭尾大如豆厥厥然動搖（傷寒論云陰陽相搏名曰動陽動則汗出陰動則發熱形冷惡寒數脉見於關上上下無頭尾如豆大厥厥動搖者名曰動）
浮與芤相類（與洪相類）　弦與緊相類（與實相類）　革與實相類（千金翼云牢與實相類）　滑與數相類　沈與伏相類　微與濇相類　軟與遲相類
```
> 备注：本页续列虚散缓迟结代动脉定义，并总结"脉相类"七组（浮芤、弦紧、革实、滑数、沉伏、微涩、软迟），供鉴别相似脉象。

## MJ-P012｜卷一·平脉早晏法第二 / 分別三關境界脉候所主第三

```
（軟與弱相類　緩與遲相類）
平脉早晏法第二
黃帝問曰夫診脉常以平旦何也岐伯對曰平旦者陰氣未動陽氣未散飲食未進經脉未盛絡脉調均（內經作氣血未亂）故乃可診過此非也（千金同素問太素示云有過之脉）切脉動靜而視精明察五色觀五藏有餘不足六府強弱形之盛衰以此參伍決死生之分
分別三關境界脉候所主第三
從魚際至高骨（自骨却行一寸其中名曰寸口）從寸至尺名曰尺澤故曰尺寸寸後尺前名曰關陽出陰入以關為界陽出三分陰入三分故曰三陰三陽陽生於尺動於寸陰生於寸動於尺寸主射上焦出頭（至足）
```
> 备注：平旦诊脉原理（阴气未动、气血未乱）与寸关尺三关境界划分，是脉诊操作总纲。

## MJ-P013｜卷一·辨尺寸陰陽榮衛度數第四

```
（及皮毛竟手關主射中焦腹及腰尺主射下焦少腹至足）
辨尺寸陰陽榮衛度數第四
夫十二經皆有動脉獨取寸口以決五藏六府死生吉凶之候者何謂也然寸口者脉之大會手太陰之動脉也人一呼脉行三寸一吸脉行三寸呼吸定息脉行六寸人一日一夜凡一萬三千五百息脉行五十度周於身漏水下百刻榮衛行陽二十五度行陰亦二十五度為一周（晬時也）故五十度而復會於手太陰太陰者寸口也即五藏六府之所終始故法取於寸口
脉有尺寸何謂也然尺寸者脉之大會要也從關至（尺是尺內陰之所治也）
```
> 备注：独取寸口的经典依据（脉之大会、五脏六腑终始），以呼吸定息计脉行度数。

## MJ-P014｜卷一·辨尺寸陰陽榮衛度數第四（续）/ 平脉視人大小長短男女逆順法第五

```
（尺是尺內陰之所治也）從關至魚際是寸口內陽之所治也故分寸為尺分尺為寸故陰得尺內一寸陽得寸內九分尺寸終始一寸九分故曰尺寸也
脉有太過有不及有陰陽相乘有覆有溢有關有格何謂也然關之前者陽之動也脉當見九分而浮過者法曰太過減者法曰不及遂上魚為溢為外關內格此陰乘之脉也關之後者陰之動也脉當見一寸而沈過者法曰太過減者法曰不及遂入尺為覆為內關外格此陽乘之脉故曰覆溢是其真藏之脉也人不病自死
平脉視人大小長短男女逆順法第五
凡診脉當視其人大小長短及性氣緩急脉之遲速（大小長短皆如其人形性者則吉反之者則為逆也）
```
> 备注：覆溢、关格的定义——覆溢为真脏之脉，"人不病自死"，是危重脉象判断依据。

## MJ-P015｜卷一·平脉視人大小長短男女逆順法第五（续）/ 持脉輕重法第六

```
大小長短皆如其人形性者則吉反之者則為逆也
脉三部大都欲等只如小人細人婦人脉小軟小兒四五歲脉呼吸八至細數者吉（千金翼云人大而脉細人小而脉大性急而脉緩性緩而脉躁人壯而脉細人羸而脉大此皆為逆逆則難治反此為順又虚人脉浮）
持脉輕重法第六
脉有輕重何謂也然初持脉如三菽之重與皮毛相得者肺部也（菽者小豆言脉輕如三小豆之重皮毛之間者肺氣所行故言肺部也）如六菽之重與血脉相得者心部也（心主血脉次於肺如六豆之重）如九菽之重與肌肉相得者脾部也（脾在中央主肌肉故次心如九豆之重）如十二菽之重與筋平者肝部也（肝主筋又在脾下故次之）
```
> 备注：持脉轻重法以"菽之重"分寸口五层（肺皮毛→心血脉→脾肌肉→肝筋→肾骨），是分层候脏腑的诊断手法。

## MJ-P016｜卷一·持脉輕重法第六（续）/ 兩手六脉所主五藏六府陰陽逆順第七

```
（按之至骨舉之來疾者腎部也　脉沈至骨故曰腎也　按之至骨舉之來疾者為腎是故輕重也）
兩手六脉所主五藏六府陰陽逆順第七
脉法讚云肝心出左脾肺出右腎與命門俱出尺部魂魄穀神皆見寸口左主司官右主司府左大順男右大順女關前一分人命之主左為人迎右為氣口神門決斷兩在關後人無二脉病死不愈諸經損減各隨其部察按陰陽誰與先後（千金云三陰三陽先誰在後）陰病治官陽病治府奇邪所舍如何捕取審而知者針入病愈
心部在左手關前寸口是也即手少陰經也與手太陽為表里以小腸合為府合於上焦名曰神庭在龜（尾下一五分）
```
> 备注：两手六脉分主五脏六腑——左关前寸口为心（手少阴），并确立人迎、气口、神门的诊断地位。

## MJ-P017｜卷一·兩手六脉所主五藏六府陰陽逆順第七（续·脏腑部位）

```
肝部在左手關上是也足厥陰經也與足少陽為表里以膽合為府合於中焦名曰胞門（一作少陽在大倉左）
右三部
腎部在左手關後尺中是也足少陰經也與足太陽為表里以膀胱合為府合於下焦在關元左
肺部在右手關前寸口是也手太陰經也與手陽明為表里以大腸合為府合於上焦名呼吸之府在雲門
脾部在右手關上是也足太陰經也與足陽明為表里以胃合為府合於中焦脾胃之間名曰章門在季脅前一寸半
腎部在右手關後尺中是也足少陰經也與足太陽為表里以膀胱合為府合於下焦在關元右左屬腎
```

## MJ-P018｜卷一·辨藏府病脉陰陽大法第八 / 辨脉陰陽大法第九

```
（右為子戶名曰三焦）
辨藏府病脉陰陽大法第八
脉何以知藏府之病也然數者府也遲者藏也數即生寒諸陽為熱諸陰為寒故別知藏府之病也（遲者陽行遲故其脉數藏者陰行疾故其脉遲行疾病則促）
脉來浮大者此為肺脉也脉來沈滑如石腎脉也脉來如弓弦者肝脉也脉來疾去遲心脉也脉來當見而不見為病病有深淺但當知如何受邪
辨脉陰陽大法第九
脉有陰陽之法何謂也然呼出心與肺吸入腎與肝呼吸之間脾受穀味也其脉在中浮者陽也沈者陰也故曰陰陽
```
> 备注：以数/迟分腑病脏病、诸阳为热诸阴为寒；并给出肺浮大、肾沉滑如石、肝如弓弦、心疾去迟的脏腑平脉形态。

## MJ-P019｜卷一·辨脉陰陽大法第九（续）

```
心肺俱浮何以別之然浮而大散者心也浮而短濇者肺也腎肝俱沈何以別之然牢而長者肝也按之濡舉指來實者腎也脾者中州故其脉在中（千金翼云遲緩而長者脾也是陰陽之脉也）
脉有陽盛陰虛陰盛陽虛何謂也然浮之損小沈之實大故曰陰盛陽虛沈之損小浮之實大故曰陽盛陰虛是陰陽虛實之意也（陽脉見寸口浮而實大今輕手浮之更損減而沈手按之更實大故言陰實陽虛）
經言脉有一陰一陽一陰二陽一陰三陽有一陽一陰一陽二陰一陽三陰如此言之寸口有六脉俱動耶然經言如此者非有六脉俱動也謂浮沈長短滑濇也浮者陽也滑者陽也長者陽也沈者陰也濇者陰也短者陰也
```
> 备注：浮大散为心、浮短涩为肺、牢长为肝、按濡举实为肾的鉴别；浮沉损小/实大判断阴阳虚实。

## MJ-P020｜卷一·辨脉陰陽大法第九（续·病脉主证）

```
（也一陰二陽者謂脉來沈滑而長也一陰三陽者謂）
脉來浮滑而長時一沈也所以言一陽二陰者謂脉來長而沈濇也一陽三陰者謂脉來沈濇而短時一浮也各以其經所在名病之逆順也凡脉大為陽浮為陽數為陽動為陽長為陽滑為陽沈為陰濇為陰弱為陰弦為陰短為陰微為陰是為三陰三陽也
陽病見陰脉者反也主死陰病見陽脉者順也主生關前為陽關後為陰陽數則吐血陰微則下利陽弦則頭痛陰弦則腹痛陽微則發汗陰微則自下陽數口生瘡陰數加微必惡寒而煩撓不得眠也陰附陽則狂陽附陰則癲得陽屬府得陰屬藏無陽則厥無陰則嘔陽微則不能呼（吸）
```
> 备注：本页为脉证对应核心条文——阳病见阴脉主死、阴病见阳脉主生；阳数吐血、阴微下利、阳弦头痛、阴弦腹痛等直接以脉断证。

## MJ-P021｜卷一·辨脉陰陽大法第九（续·阴阳病证）

```
（陰微則不能吸）呼不足骨中短氣依此陰陽以察病也
寸口脉浮大而疾者名曰陽中之陽病苦煩滿身熱頭痛腹中熱
寸口脉沈細者名曰陽中之陰病苦悲傷不樂惡聞人聲少氣時汗出陰氣不通臂不能舉
尺脉沈細者名曰陰中之陰病苦兩脛酸疼不能久立陰氣衰小便餘瀝陰下濕癢
尺脉滑而浮大者名曰陰中之陽病苦小腹痛滿不能溺溺即陰中痛大便亦然
尺脉牢而長關上無有此為陰干陽其人苦兩脛重少腹引腰痛
```
> 备注：阳中之阳/阴、阴中之阴/阳四类的具体病证（烦满身热、悲伤少气、胫酸小便余沥、小腹痛满等），是脉象直接对应症状的条文。

## MJ-P022｜卷一·平虛實第十

```
（寸口脉壯大尺中無有此為陽干陰其人苦腰背痛）
陰中傷足脛寒夫風傷陽寒傷陰陽病順陰病逆陰病易治陽病難治在腸胃之間以藥和之若在經脉之間針灸病已
平虛實第十
人有三虛三實何謂也然有脉之虛實有病之虛實有診之虛實脉之虛實者脉來耎者為虛牢者為實病之虛實者出者為虛入者為實言者為虛不言者為實緩者為虛急者為實診之虛實者痒者為虛痛者為實外痛內快為外實內虛內痛外快為內實外虛故曰虛實也
問曰何謂虛實答曰邪氣盛則實精氣奪則虛何謂（虛）
```
> 备注："邪气盛则实、精气夺则虚"的虚实总纲，以及脉/病/诊三层面虚实判别。

## MJ-P023｜卷一·從橫逆順伏匿脉第十一

```
重實所謂重實者言大熱病氣熱脉滿是謂重實
問曰經絡俱實如何何以治之答曰經絡皆實是寸脉急而尺緩也當俱治之故曰滑則順濇則逆夫虛實者皆從其物類始五藏骨肉滑利可以長久
從橫逆順伏匿脉第十一
問曰脉有相乘有從有逆有橫有順何謂也師曰水行乘火金行乘木名曰從火行乘水木行乘金名曰橫水行乘金火行乘木名曰逆金行乘水木行乘火名曰順
經言脉有伏匿者伏匿於何藏而言伏匿也然謂陰陽更相乘更相伏也脉居陰部反見陽脉者為陽乘陰也脉雖時沈濇而短此陽中伏陰脉居陽部反見陰脉者為陰乘陽（也）
```
> 备注：五行相乘的从/横/逆/顺判断（水乘火为从、火乘水为逆等）与阴阳伏匿，用于判断病势顺逆。

## MJ-P024｜卷一·辯災怪恐怖雜脉第十二

```
（陽也重陰者癲重陽者狂脫陽者見鬼脫陰者目盲）
辯災怪恐怖雜脉第十二
問曰脉有殘賊何謂師曰脉有弦有緊有濇有滑有浮有沈此六脉為殘賊能與諸經作病
問曰嘗為人所難緊脉何所從而來師曰假令亡汗若吐肺中寒故令緊假令欬者坐飲冷水故令緊假令下利者以胃中虛冷故令緊也
問曰翕奄沈名曰滑何謂師曰沈為純陰翕為正陽陰陽和合故脉滑也
問曰脉有災怪何謂師曰假令人病脉得太陽脉與病形證相應該為作湯比還送湯之時病者因反大（吐下）
```
> 备注：残贼六脉（弦紧涩滑浮沉）能随各经作病；紧脉成因（亡汗、吐肺中寒、饮冷水、胃虚冷），是"由脉溯因"的典型条文。

## 二、《濒湖脉学》BH（二十七脉 · 体状诗/相类诗/主病诗）

> 底本为明·李时珍《濒湖脉学》（奇经八脉考·脉诀考证合集本）。二十七脉依次排列，每脉含脉形定义、体状诗、相类诗、主病诗及主病提纲。此书是"看脉象描述断病因"的核心，逐脉照录。

## BH-P014｜濒湖脉学·序 / 浮脉（起）

```
瀕湖脉學
李時珍曰宋有俗子杜撰脉訣鄙陋紕繆醫學習誦以為權輿逮臻頌自脉理竟昧戴同父嘗刑其誤先考月池翁著四診發明八卷皆精詣奧室淺學未能窺造因撮粹擷華僭撰此書以便習讀為脉指南世之醫病兩家咸以脉為首務不知脉乃四診之末謂之巧者爾上士欲會其全非備四診不可惟明嘉靖甲子上元日謹書於瀕湖薖所
浮　陽
```
> 备注：李时珍自序，交代撰述缘由（撮四诊发明之粹华以便习读），并强调脉为四诊之末、须四诊相参。

## BH-P015｜浮脉·体状诗/相类诗

```
浮脉舉之有餘按之不足（脉經）如微風吹鳥背上毛厭厭聶聶（輕沉）如循榆莢（素問）如木浮水（崔氏）如捻蔥葉（黎氏）
浮脉法天有輕清在上之象在卦為乾在時為秋在人為肺又謂之毛太過則中堅旁虛如循雞羽病在外也不及則氣來毛微病在中也（脉訣言尋之如太過乃浮兼洪緊之象非浮脉也）
體狀詩　浮脉惟從肉上行如循榆莢似毛輕三秋得令知無恙久病逢之郤可驚
相類詩　浮如木在水中浮浮大中空乃是芤拍拍而浮是洪脉來時雖盛去悠悠○浮脉輕平似捻蔥虛來遲大豁然空浮而柔細方為濡散似楊花無定蹤
```
> 备注：浮脉形态（举有余按不足、如风吹鸟背毛）与体状/相类诗；浮脉主表、法天、在肺。

## BH-P016｜浮脉·主病诗 / 沉脉（起）

```
浮而有力為洪　浮而遲大為虛　虛甚為散　浮而無力為芤　浮而柔細為濡
主病詩　浮脉為陽表病居遲風數熱緊寒拘浮而有力多風熱無力而浮是血虛○寸浮頭痛眩生風或有風痰聚在胸關上土衰兼木旺尺中溲便不流通
浮脉主表有力表實無力表虛　浮數風熱　浮緊風寒　浮緩風濕　浮虛傷暑　浮芤失血　浮洪虛熱　浮散勞極
沈　陰
沈脉重手按至筋骨乃得（脉經）如綿裹砂內剛外柔（楊氏）如石投水必極其底
```
> 备注：浮脉主病核心——"浮脉为阳表病居，迟风数热紧寒拘"，并浮数风热、浮紧风寒、浮缓风湿、浮芤失血等配伍主病；沉脉起。

## BH-P017｜沉脉·体状诗/相类诗/主病诗

```
沈脉法地有淵泉在下之象在卦為坎在時為冬在人為腎又謂之石亦曰營太過則如彈石按之益堅病在外也不及則氣來虛微去如數者病在中也（脉訣言緩度三關狀如爛綿者非也沈有緩數及各部之沈爛綿乃弱脉非沈也）
體狀詩　水行潤下脉來沈筋骨之間奕滑勻女子寸方男子尺四時如此號為平
相類詩　沈幫筋骨自調勻伏則推筋著骨尋沈細如綿真弱脉弦長實大是牢形（沈行筋間伏行骨上牢大有力弱細無力）
主病詩　沈潜水畜陰經病數熱遲寒滑有痰無力而沈虛與氣沈而有力積并寒○寸沈痰欝水停胸關主中寒痛不通尺部濁遺并泄痢腎虛腰及下元痼
沈脉主裏有力裏實無力裏虛　沈則為氣又主水畜　沈數內熱　沈滑痰食　沈濇氣鬱　沈弱寒熱　沈緩寒濕　沈緊冷痛　沈牢冷積
```
> 备注：沉脉主里——"沉潜水畜阴经病，数热迟寒滑有痰"，沉数内热、沉滑痰食、沉紧冷痛等，直接对应病因。

## BH-P018｜迟脉·体状诗/相类诗/主病诗

```
遲　陰
遲脉一息三至去來極慢（脉經）
遲為陽不勝陰故脉來不及（脉訣言重手乃得是有沈無浮一息三至甚為易見而曰隱隱曰狀且難是濇脉矣其謬可知）
體狀詩　遲來一息至惟三陽不勝陰氣血寒但把浮沈分表裏消陰須益火之原
相類詩　脉來三至號為遲小駃于遲作緩持遲細而難知是濇浮而遲大以虛推（三至為遲有力為緩無力為濇遲甚為敗浮大而耎為虛○黎氏曰遲小而實緩大而慢遲為陰盛陽衰緩為衛盛營弱宜別之）
主病詩　遲司藏病或多痰沈痼癥瘕子細看有力而遲為冷痛遲而無力定虛寒○寸遲必是上焦寒關主中寒痛不堪尺是腎虛腰脚重溲便不禁疝牽丸
遲脉主藏有力冷痛無力虛寒　浮遲表寒　沈遲裏寒
```
> 备注：迟脉主脏、主寒——"迟司脏病或多痰……有力而迟为冷痛，迟而无力定虚寒"，是寒证判断核心。

## BH-P019｜数脉·体状诗/相类诗/主病诗

```
數　陽
數脉一息六至（脉經）脉流薄疾（素問）
數為陰不勝陽故脉來太過（浮沈遲數脉之綱領　素問脉經皆為正脉脉訣立七表八裏而遺數脉其妄甚矣）
體狀詩　數脉息間常六至陰微陽盛必狂煩浮沈表裏分虛實惟有兒童作吉看
相類詩　數比平人多一至緊來如數似彈繩數而時止名為促數見關中動脉形（數而弦急為緊流利為滑數而有止為促數甚為極見關中為動）
主病詩　數脉為陽熱可知只將君相火來醫實宜凉瀉虛溫補肺病秋深却畏之○寸數咽喉口舌瘡吐（紅咳嗽）
數脉主府有力實火無力虛火　浮數表熱　沈數裏熱　氣口數實肺癰　數虛肺痿
```
> 备注：数脉主腑、主热——"数脉为阳热可知，只将君相火来医，实宜凉泻虚温补"，数脉为热证核心依据。

## BH-P020｜滑脉·体状相类诗/主病诗

```
滑　陽中陰
滑脉往來前却流利展轉替替然如珠之應指（脉經）漉漉如欲脫（滑為陰氣有餘故脉來流利如水脉者血之府也血盛則脉滑故腎脉宜之○脉訣云按之即伏三關如珠不進不退是不分浮滑沈滑尺寸之滑也今正之）
體狀相類詩　滑脉如珠替替然往來流利却還前莫將滑數為同類數脉惟看至數間（滑則如珠數則六至）
主病詩　滑脉為陽元氣衰痰生百病食生灾上為吐（逆下畜血女脉調時定有胎）○寸滑膈痰生嘔吐吞酸舌强或咳嗽當關宿食肝脾熱渴痢痾淋看尺部
滑主痰飲　浮滑風痰　沈滑食痰　滑數痰火　滑短宿食
```
> 备注：滑脉主痰——"滑脉为阳元气衰，痰生百病食生灾"，浮滑风痰、沉滑食痰、滑数痰火，是痰证判断核心。

## BH-P021｜涩脉·体状诗/相类诗/主病诗

```
濇　陰
濇脉細而遲往來難短且散或一止復來（脉經）參伍不調（素問）如輕刀刮竹（脉訣）如雨沾沙（通真子）如病蠶食葉
濇為陽氣有餘氣盛則血少故脉來蹇滯而肺宜之（脉訣言指下尋之似有舉之全無與脉經所云絕不相干）
體狀詩　細遲短濇往來難散止依稀應指間如雨沾沙容易散病蠶食葉慢而艱
相類詩　參伍不調名曰濇輕刀刮竹短而難微似秒芒微與甚浮沈不別有無間（細遲短散時一止曰濇細而柔細曰濡極細而耎重按若絕曰微浮而柔細曰濡沈而柔細曰弱）
主病詩　濇緣血少或傷精反胃亡陽汗雨淋寒濕入營為血痹女人非孕即無經○寸濇心虛痛對胸胃虛脅脹察關中尺為精血俱傷候腸結溲淋或下紅
濇主血少精傷之病女人有孕為胎病無孕為敗血（杜光庭云濇脉獨見尺中形同代脉為死脉）
```
> 备注：涩脉主血少精伤——"涩缘血少或伤精……女人非孕即无经"，是血虚、精伤、血瘀证依据。

## BH-P022｜虚脉·体状相类诗/主病诗

```
虛　陰
虛脉遲大而耎按之無力隱指豁豁然空（脉經）
崔紫虛云形大力薄其虛可知（脉訣言尋之不足舉之有餘止言浮脉不見虛狀楊仁齋言狀似柳絮散漫而遲滑氏言散大而耎皆是散脉非虛也）
體狀相類詩　舉之遲大按之松脉狀無涯類谷空莫把芤虛為一例芤來浮大似慈葱（虛脉浮大而遲按之無力芤脉浮大按之中空芤為脫血虛為血虛浮散二脉見浮脉）
主病詩　脉虛身熱為傷暑自汗怔忡驚悸多發熱陰虛須早治養營益氣莫蹉跎○血不榮心寸口虛關中腹脹食難舒骨蒸痿痹傷精血却在神門兩部居
（經曰血虛脉虛曰氣來虛微為不及病在內曰久病脉虛者死）
```
> 备注：虚脉主虚——"脉虚身热为伤暑，自汗怔忡惊悸多"，虚为血虚、芤为脱血的鉴别；久病脉虚者死。

## BH-P023｜实脉·体状相类诗/主病诗

```
實　陽
實脉浮沈皆得脉大而長微弦應指愊愊然（脉經）
愊愊堅實貌（脉訣言如繩牽來乃緊脉非實脉也）
體狀詩　浮沈皆得大而長應指無虛愊愊强熱蘊三焦成壯火通腸發汗始安康
相類詩　實脉浮沈有力强緊如彈索轉無常須知牢脉幫筋骨實大微弦更帶長（浮沈有力為實弦急彈人為緊沈而實大微弦而長為牢）
主病詩　實脉為陽火鬱成發狂譫語吐頻頻或為陽毒或傷食大便不通或氣疼○寸實應知面熱風咽疼舌强氣填胸當關脾熱中宫滿尺實腰腸痛不通
（經曰血實脉實曰脉實者水穀為病曰氣來實强是謂太過）
```
> 备注：实脉主火郁、阳毒、伤食——"实脉为阳火郁成，发狂谵语吐频频"，实证、热结依据。

## BH-P024｜长脉·短脉

```
長　陽
長脉不大不小迢迢自若（朱氏）如循長竿末梢為平如引繩如循長竿為病（素問）
長有三部之長一部之長在時為春在人為肝心脉長神强氣壯腎脉長蒂固根深經曰長則氣治皆言平脉也
體狀相類詩　過于本位脉名長弦則非然但滿張弦脉與長争較遠良工尺度自能量（實牢弦緊皆兼長脉）
主病詩　長脉迢迢大小勻反常為病似牽繩若非陽毒癲癇病即是陽明熱勢深（長主有餘之病）
短　陰
短脉不及本位（脉經）應指而迴不能滿部（脉經）（戴同父云短脉只見尺寸若關中見短上不通寸下不通尺是陰陽絕脉必死矣故關不診短）
```
> 备注：长主有余（阳毒癫痫、阳明热势），短主不及；关中见短为阴阳绝脉。

## BH-P025｜洪脉·体状诗/相类诗/主病诗

```
洪　陽
洪脉指下極大（脉經）來盛去衰（素問）來大去長（通真子）
洪脉在卦為離在時為夏在人為心素問謂之大（鈎）亦曰鈎滑氏曰來盛去衰如鈎之曲上而復下應（血脉來去之象萬物敷布下垂之狀○詹炎舉言如環珠者非脉訣云季夏宜之秋季冬季發汗通陽俱非洪脉所宜蓋謬也）
體狀詩　脉來洪盛去還衰滿指滔滔應夏時若在春秋冬月分升陽散火莫狐疑
相類詩　洪脉來時拍拍然去衰來盛似波瀾欲知實脉參差處舉按弦長愊愊堅（洪而有力為實實而無力為洪）
主病詩　脉洪陽盛血應虛相火炎炎熱病居脹滿胃翻須早治陰虛泄痢可愁如○寸洪心火上焦炎肺脉洪時金不堪肝火胃虛關內察腎虛陰火尺中看
洪主陽盛陰虛之病泄痢失血久嗽者忌之（經曰形瘦脉大多氣者死曰脉大則病進）
```
> 备注：洪脉主阳盛阴虚、相火炎热病——"脉洪阳盛血应虚，相火炎炎热病居"，泄痢失血久嗽者忌。

## BH-P026｜微脉·体状相类诗/主病诗

```
微　陰
微脉極細而耎按之如欲絕若有若無（脉經）細而稍長（戴氏○素問謂之小氣血微則脉微）
體狀相類詩　微脉輕微瞥瞥乎按之欲絕有如無微為陽弱細陰弱細比于微略較粗（輕診即見重按如欲絕者微也往來如線而常有者細也仲景曰脉瞥瞥如羹上肥者陽氣微縈縈如蚕絲細者陰氣衰長病得之死卒病得之生）
主病詩　氣血微兮脉亦微惡寒發熱汗淋漓男為勞（極諸虛候女作崩中帶下醫）○寸微氣促或心驚關脉微時脹滿形尺部見之精血弱惡寒消癉痛呻吟
微主久虛血弱之病陽微惡寒陰微發熱崩中帶下脉微者忌之（脉訣云歲中日久為白帶漏下多時骨亦枯）
```
> 备注：微脉主久虚血弱——"气血微兮脉亦微，恶寒发热汗淋漓"，阳微恶寒、阴微发热。

## BH-P027｜紧脉·体状诗/主病诗

```
緊　陽
緊脉來往有力左右彈人手（素問）如轉索無常（仲景）數如切繩（脉經）如紉箪線（丹溪）
緊乃熱為寒束之脉故急數如此要有神氣素問謂之急（脉訣言寥寥入尺來崔氏言如線皆非緊狀或以浮緊為弦沈緊為牢亦近似耳）
體狀詩　舉如轉索切如繩脉象因之得緊名總是寒邪來作寇內為腹痛外身疼
主病詩　緊為諸痛主于寒喘咳風癇吐冷痰浮緊表寒須發越緊沈溫散自然安○寸緊人迎氣口分當關心腹痛沈沈尺中有緊為陰冷定是奔豚與病疼
（諸緊為寒為痛人迎緊盛傷于寒氣口緊盛傷于食尺緊痛居其腹中惡浮緊咳嗽沈緊皆主死）
```
> 备注：紧脉主寒、主痛——"总是寒邪来作寇，内为腹痛外身疼"，人迎紧伤寒、气口紧伤食。

## BH-P028｜缓脉·体状诗/主病诗

```
緩　陰
緩脉去來小駃于遲（脉經）一息四至（戴氏）如絲在經不卷其軸應指和緩往來甚勻（張太素）如初春楊柳舞風之象（楊玄）如微風輕颭柳梢（滑伯仁）

## ST-P004｜舌胎圖說·目錄 / 白胎舌總論（起）

```

白胎舌　九圖
黃胎舌　七圖
黑胎舌　九圖
紅色舌　十四圖

舌胎圖說
白胎舌總論
張氏古鑑曰（舌）偶曰寒邪在皮毛初則舌有白沫次則白涎白滑再次白屑白葩有舌中舌尖舌根之不同是寒邪入經之微甚也（甚）恐未必然也此以其邪之微甚而言之一可謂鑿矣然邪氣在皮毛則舌（必）未生胎及其傳裏則津液乾燥而舌生胎矣然邪猶未深而在半表半裏則津液亦未（耗）其舌（色）未深而在半表半裏津液乃（竭）陽明也（邪）已深則舌變為黃（黃胎舌變而為黑則邪已深病已極此）
