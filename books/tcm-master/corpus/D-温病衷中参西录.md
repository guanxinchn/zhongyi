## WB-P030｜卷一·上焦篇（书内页12）风温 温热 温疫 温毒 冬温
```
卷一 上焦篇
風溫 溫熱 溫疫 溫毒 冬溫
一、溫病者：有風溫、有溫熱、有溫疫、有溫毒、有暑溫、有濕溫、有秋燥、有冬溫、有溫瘧。
此九條，見于王叔和《傷寒例》中居多，叔和又牽引《難經》之文以神其說。按時推病，實有是証，叔和治病時，亦實遇是証。但叔和不能別立治法，而敘于《傷寒例》中，實屬蒙混，以《傷寒論》為治外感之妙法，遂將一切外感悉收入傷寒例中，而悉以治傷寒之法治之（心苦為分明。——朱評）。後人亦不能打破此關，因仍苟簡，千餘年來，貽患無窮，皆叔和之作俑，無怪見駭于方有執、喻嘉言諸公也。然諸公雖駁叔和，亦未曾另立方法，喻氏雖立治法，仍不能脫卻傷寒圈子，弊與叔和無二，以致後人無所遵依。本論詳加考核，準古酌今，細立治法，除傷寒宗仲景法外，俾四時雜感，朗若列眉；未始非叔和有以肇其端，東垣、河間、安道、又可、嘉言、天士宏其議，而瑭得以善其後也。
風溫者，初春陽氣始開，厥陰行令，風夾溫也。溫熱者，春末夏初，陽氣馳張，溫盛為熱也。溫疫者，厲氣流行，多兼穢濁，家家如是，若役使然也。溫毒者，諸溫夾毒，穢濁太甚也。暑溫者，正夏之時，暑病之偏于熱者也。濕溫者，長夏初秋，濕中生熱，即暑病之偏于濕者也。秋燥者，秋金燥烈之氣也。冬溫者，冬應寒而反溫，陽不潛藏，民病溫也。溫瘧者，陰氣先傷，又因于暑，陽氣獨發也。
```
> 备注：温病总论纲领，列举风温、温热、温疫、温毒、暑温、湿温、秋燥、冬温、温疟九种，为全书大纲。

傷寒由毛竅而入，自下而上，始足太陽。足太陽膀胱屬水，寒即水之氣，同類相從，故病始于此。古來但言膀胱主表，殆未盡其義。肺者，皮毛之合也，獨不主表乎（按人身一臟一腑主表之理，人皆習焉不察。以三才大道言之：天為萬物之大表，天屬金，人之肺亦屬金，肺主皮毛，經曰皮應天，天一生水；地支始生于子，而亥為天門，乃元氣之會；人之膀胱為寒水之腑，故俱同天氣，而俱主表也）！治法必以仲景六經次傳為祖法。溫病由口鼻而入，自上而下，鼻通于肺，始手太陰。太陰金也，溫者火之氣，風者火之母，火未有不克金者，故病始于此，必從河間三焦定論。再寒為陰邪，雖《傷寒論》中亦言中風，此風從西北方來，乃□發之寒風也，最善收引，陰盛必傷陽，故首郁遏太陽經中之陽氣，而為頭痛身熱等証。太陽陽腑也，傷寒陰邪也，陰盛傷人之陽也。溫為陽邪，此論中亦言傷風，此風從東方來，乃解凍之溫風也，最善發泄，陽盛必傷陰，故首郁遏太陰經中之陰氣，而為咳嗽自汗口渴頭痛身熱尺熱等証。太陰陰臟也，溫熱陽邪也，陽盛傷人之陰也。陰陽兩大法門之辨，可了然于心目之間矣（提綱。——朱評）。

## WB-P032｜卷一·上焦篇（书内页14）
```
南也。由西而往，為金、為燥、為水、為寒，水也者，北也。水火者，陰陽之征兆也；南北者，陰陽之極致也。天地運行此陰陽以化生萬物，故曰天之無恩而大恩生。天地運行之陰陽和平，人生之陰陽亦和平，安有所謂病也哉！天地與人之陰陽，一有所偏，即為病也。偏之淺者病淺，偏之深者病深；偏于火者病溫、病熱，偏于水者病清、病寒，此水火兩大法門之辨，醫者不可不知。燭其為水之病也，而溫之熱之；燭其為火之病也，而涼之寒之，各救其偏，以抵于平和而已。非如鑒之空，一塵不染，如衡之平，毫無倚著，不能暗合道妙，豈可各立門戶，專主于寒熱溫涼一家之論而已哉！瑭因辨寒病之原于水，溫病之原于火也，而並及之。
三、太陰之為病，脈不緩不緊而動數，或兩寸獨大，尺膚熱，頭痛，微惡風寒，身熱自汗，口渴，或不渴，而咳，午後熱甚者，名曰溫病。
不緩，則非太陽中風矣；不緊，則非太陽傷寒矣；動數者，風火相煽之象，經謂之躁；兩寸獨大，火克金也。尺膚熱，尺部肌膚熱甚，火反克水也。頭痛、惡風寒、身熱自汗，與太陽中風無異；此處最足以相混，于何辨之？于脈動數，不緩不緊，証有或渴、或咳、尺熱、午後熱甚辨之。太陽頭痛，風寒之邪，循太陽經上至頭與項，而項強頭痛也。太陰之頭痛，肺主天氣，天氣郁，則頭亦痛也，且春氣在頭，又火炎上也。傷寒之惡寒，太陽屬寒水而主表，故惡風寒；溫病之惡寒，肺合皮毛而亦主表，故亦惡風寒也。太陽病則周身之陽氣郁，故身熱；肺主化氣，肺病不能化氣，氣郁則身亦熱也。
```
> 备注：温病脉证提纲（第三条）——"脉不缓不紧而动数，或两寸独大，尺肤热，头痛，微恶风寒，身热自汗，口渴，或不渴，而咳，午后热甚者，名曰温病"，为辨证核心。

## WB-P033｜卷一·上焦篇（书内页15）
```
太陽自汗，風疏衛也；太陰自汗，皮毛開也，肺亦主衛。渴，火克金也。咳，肺氣郁也。午後熱甚，濁邪歸下，又火旺時也，又陰受火克之象也。
四、太陰風溫、溫熱、溫疫、冬溫，初起惡風寒者，桂枝湯主之；但熱不惡寒而渴者，辛涼平劑銀翹散主之。溫毒、暑溫、濕溫、溫瘧，不在此例。
按仲景《傷寒論》原文，太陽病（謂如太陽証，即上頭痛身熱惡風自汗也），但惡熱不惡寒而渴者，名曰溫病，桂枝湯主之。蓋溫病忌汗，最喜解肌，桂枝本為解肌，且桂枝芳香化濁，芍藥收斂陰液，甘草敗毒和中，姜、棗調和營衛，溫病初起，原可用之。此處卻變易前法，惡風寒者主以桂枝，不惡風寒主以辛涼者，非敢擅違古訓也。仲景所云不惡風寒者，非全不惡風寒也，其先亦惡風寒，迨既熱之後，乃不惡風寒耳，古文簡質，且對太陽中風熱時亦惡風寒言之，故不暇詳耳。蓋寒水之病，冬氣也，非辛溫春夏之氣，不足以解之，雖曰溫病，既惡風寒，明是溫自內發，風寒外搏，成內熱外寒之証，故仍舊用桂枝辛溫解肌法，俾得微汗，而寒熱之邪皆解矣。溫熱之邪，春夏氣也，不惡風寒，則不兼寒風可知，此非辛涼秋金之氣，不足以解之。桂枝辛溫，以之治溫，是以火濟火也，故改從內經"風淫于內、治以辛涼、佐以苦甘"法。
桂枝湯方
桂枝六錢 芍藥（炒）三錢 炙甘草二錢 生姜三片 大棗（去核）二枚
```
> 备注：第四条为银翘散证的总纲——"但热不恶寒而渴者，辛凉平剂银翘散主之"；并辨桂枝汤用于温病初起恶风寒者之理。附桂枝汤方。

## WB-P034｜卷一·上焦篇（书内页16）
```
煎法服法，必如傷寒論原文而後可，不然，不惟失桂枝湯之妙，反生他變，病必不除。
汪按：麻黃、桂枝，既系肺藥，故傳足不傳手，前人多不以為然，但人之經絡相通，而天之臟氣則異，故治法不同也。
辛涼平劑銀翹散方
連翹一兩 銀花一兩 苦桔梗六錢 薄荷六錢 竹葉四錢 生甘草五錢 芥穗四錢 淡豆豉五錢 牛蒡子六錢
上杵為散，每服六錢，鮮葦根湯煎，香氣大出，即取服，勿過煎。肺藥取輕清，過煎則味厚而入中焦矣。病重者，約二時一服，日三服，夜一服；輕者三時一服，日二服，夜一服；病不解者，作再服。蓋肺位最高，藥過重，則過病所，少用又有病重藥輕之患，故從普濟消毒飲時時輕揚法（妙甚。——朱評）。今人亦間有用辛涼法者，多不見效，蓋病大藥輕之故，一不見效，隨改弦易轍，轉去轉遠，即不更張，緩緩延至數日後，必成中下焦証矣。胸膈悶者，加藿香三錢、郁金三錢，護膻中；渴甚者，加花粉；項腫咽痛者，加馬勃、元參；衄者，去芥穗、豆豉，加白茅根三錢、側柏炭三錢、梔子炭三錢；咳者，加杏仁利肺氣；二、三日病猶在肺，熱漸入里，加細生地、麥冬保津液；再不解，或小便短者，加知母、黃芩、梔子之苦寒，與麥、地之甘寒，合化陰氣，而治熱淫所勝。
〔方論〕按溫病忌汗，汗之不惟不解，反生他患。蓋病在手經，徒傷足太陽無益；病自口鼻吸受而生，徒發其表亦無益也。且汗為心液，心陽受傷，必有神明內亂、譫語癲狂、內閉外脫之變。再，誤汗雖曰傷陽，汗乃五液之一，未始不傷陰也。《傷寒論》曰："尺脈微者為里虛，禁汗，"其義可見。
```
> 备注：银翘散完整方（辛凉平剂）及煎服法、随证加减；剂量原样照录。为温病上焦核心方。

## WB-P035｜卷一·上焦篇（书内页17）
```
其日傷陽者，特舉其傷之重者而言之耳（精能之至。——朱評）。溫病最善傷陰，用藥又復傷陰，豈非為賊立幟乎？此古來用傷寒法治溫病之大錯也。至若吳又可開首立一達原飲，其意以為直透膜原，使邪速潰，其方施于藜藿壯實人之溫疫病，容有愈者，芳香辟穢之功也；若施于膏粱紈綺，及不甚壯實人，未有不敗者。蓋其方中首用檳榔、草果、厚朴為君：夫檳榔，子之堅者也，諸子皆降，檳榔苦辛而溫，體重而堅，由中走下，直達肛門，中下焦藥也；草果亦子也，其氣臭烈大熱，其味苦，太陰脾經之劫藥也；厚朴苦溫，亦中焦藥也。豈有上焦溫病，首用中下焦苦溫雄烈劫奪之品，先劫少陰津液之理！知母、黃芩，亦皆中焦苦燥里藥，豈可用乎？況又有溫邪游溢三陽之說，而有三陽經之羌活、葛根、柴胡加法，是仍以傷寒之法雜之，全不知溫病治法，後人止謂其不分三焦，猶淺說也。其三消飲加入大黃、芒硝，惟邪入陽明，氣體稍壯者，幸得以下而解，或戰汗而解，然往往成弱証，虛甚者則死矣。況邪有在衛者，在胸中者，在營者，入血者，妄用下法，其害可勝言耶？豈視人與鐵石一般，并非氣血生成者哉？
本方謹遵內經"風淫于內，治以辛涼，佐以苦甘；熱淫于內，治以咸寒，佐以甘苦"之訓（王安道《溯洄集》亦有溫暑當用辛涼不當用辛溫之論，謂仲景之書，為即病之傷寒而設，并未嘗為不即病之溫暑而設。張風逵選治暑方，亦有暑病首用辛涼，繼用甘寒，再用酸泄酸斂，不必用下之論。皆先得我心者）。又宗喻嘉言芳香逐穢之說，用東垣清心涼膈散，辛涼苦甘。病初起，且去入里之黃芩，勿犯中焦；加銀花辛涼，芥穗芳香，散熱解毒；牛蒡子辛平潤肺，解熱散結，除風利咽；皆手太陰藥也。
```
> 备注：申明银翘散立方之旨——辛凉、轻清、勿犯中下焦，批驳吴又可达原饮以苦温劫津之误。卫气营血分证思想（在卫、在胸中、在营、入血）体现。

## ZX-P083｜第三卷·三宝粥医案（原书页83）

奉天省议长李甘楠，年近四旬。因有事，连夜熬夜。陡然腹疼，继而泄泻，兼下痢。其痢多于白，上焦有热，不能饮食。其脉弦而浮，按之不实。先投以三宝粥方（方在后），服两次，腹疼与泻痢皆见轻，仍不能饮食。继用通变白头翁汤方，连服两剂，痢可进饮食，腹疼泄泻犹未全愈。后仍用三宝粥方，去鸡子黄，日服两次，数日病全愈。

## ZX-P084｜第三卷·通变白头翁汤（原书页84）
```
已之岁，寓居德州，有卢雅雨公曾孙女，年五十六。于夏季下痢赤白，迁延至仲冬不愈。延医十余人，服药百剂，皆以为无可药可医矣。其弟月潭，素通医学，偶与论及此证。月潭曰：病久气馁，日夜做热，心中烦热，但头目时或眩晕，心中微觉烦热，便时下坠作疼，然不甚剧。询其平素下焦畏凉，是以从前服药，略加温补，上即烦热，略为清解，下即腹疼作泻。此诚两难之证。愚曰：此证当用白头翁汤，加山药、阿胶、甘草（即通变白头翁汤）。然此证已延半载，气血两虚，但用寒凉，恐伤脾胃。拟以此方寒温并用，涩通并行。
疏观五条，原少腹衷急后重之病，其脉沉细而数，按之无力。愚思此证，虚无疑矣。虽曰：病在气分，然久病入络，必有瘀血。通变白头翁汤中，白头翁、秦皮、黄连、黄柏，苦寒清热解毒；加山药、阿胶、甘草，养阴润燥、缓急和中；三七、鸭蛋子化瘀解毒。如是则寒温并用，通涩兼施，庶几无弊。
戊午秋日，愚初至奉天，有铁岭李济臣年二十八。下痢四十余日，脓血杂以脂膜，腹中疼，脉数而细弱，两尺尤甚，亦治以此方。服两剂，病益剧，腹中疼益甚。诊其脉，数而细弱如故。曰：药似不对证，然所以不效者，病家之过也。盖病久滑脱，肠中脂膜已伤，非徒清热所能愈。仍用山药粥送服三七、鸭蛋子（即三宝粥法），则补涩与化瘀并行。服一剂，腹中疼止，数日而愈。
```
> 备注：通变白头翁汤治久痢（白头翁、秦皮、黄连、黄柏加山药、阿胶、甘草等）——寒温并用、通涩兼施；多则久痢滑脱医案，体现张锡纯"久病入络、气血两虚"的痢疾辨治思路。

## ZX-P085｜第三卷·通变白虎加人参汤（原书页85）
```
炒熟小茴香末一钱，连服数剂全愈。
或问：西人谓痢为肠中生炎。所谓炎者，红热肿疼，甚则腐烂也。观此案与治卢姓之案，皆用热药成功，亦可谓之肠炎乎？既非肠炎，何以其肠亦欲腐烂乎？答曰：痢证，原有寒有热。热证不愈，其肠可至腐烂，寒证久不愈，其肠亦可腐烂。譬如疮疡，红肿热痛，西医以三黄、犀角纯寒之品，满口烂尽，而色白不知疼。后医者改用肉桂、附子等品，一服知疼，连服十余剂而愈。夫人中之肌肉，犹肠中之肌肉也。口中之肌肉，可因寒凉而腐烂，肠中之肌肉，独不可因寒凉而腐烂乎？此可实证研究也。
通变白虎加人参汤
治下痢，或赤、或白、或赤白参半，下重腹疼，周身发热，服凉药而热不休，脉象确有实热者。
生石膏（细研）二两 生杭芍八钱 生山药六钱 人参五钱（野台参或辽东参皆可，辽东参则质量稍差） 甘草二钱
上五味，用水四盅，煎取清汤两盅，分二次温饮之。
此方即《伤寒论》白虎加人参汤，以芍药代知母、山药代粳米也。痢疾身热不休，服凉药而热不休者，方书多谓为阴虚，然按其脉，确有实热，知其为外感之热邪内陷，逼迫肠中脂膜腐败而下痢。此乃因外感之热邪，入于阳明，耗伤津液，故身热不休。是以重用生石膏清阳明之实热，知母、山药、人参、甘草、芍药，养阴清热、补气生津，使热退而痢自愈。
按：外感之热已入阳明胃腑，当治以苦寒，若白虎汤、承气汤是也。若治以甘寒，其病亦可暂愈，而恒将余邪锢留胃中，变为骨蒸劳热，久久不愈（详见第六卷）。夫石膏虽非苦寒，其性凉而能散（诸家本草谓其性寒之议论，参看第八卷），且无汁浆，迥与甘寒滋润者不同。而白虎汤中，必佐以知母之苦寒者，即此故也。
```
> 备注：通变白虎加人参汤完整方（生石膏二两、生杭芍八钱、生山药六钱、人参五钱、甘草二钱）——治下痢身热不休、脉有实热（白虎加人参汤变方，芍药代知母、山药代粳米）；张锡纯论痢有寒热、寒痢亦致肠腐烂，及石膏"凉而能散、非甘寒滋润"之性。

## ZX-P086｜第三卷·通变白虎加人参汤医案与痢论（原书页86）

病状，非治痢药治之不可。遂投以此汤两剂，诸病皆愈。其脉犹有余热，拟再用石膏清之。病家疑年高，石膏不可屡服，愚亦应聘他往。后二十余日，病复作。延他医治疗，于治痢药中，杂以甘寒润滋之品，致外感之余热，永留肠胃不去，其痢虽瘥，而屡次反复。延至明年仲夏，反覆甚剧。复延愚诊治，其脉象、病证皆如前。因谓之曰：去岁若肯多服石膏数剂，何至有以后屡次反复也。复投以汤，连服三剂，病愈而脉亦安和。
一人，年四十二，患白痢，常常下坠，遍半个多月。心中发热，同作寒热。医者治以痢药中，重用黄连二钱，热如故，而痢亦不愈。诊其脉，洪长有力，亦投以此汤。为其间作寒热，加柴胡二钱，一剂热退痢止。犹间有寒热之时。再诊其脉，仍似有力，而无和缓之意，知其热久，而津液有伤也。遂去白芍、柴胡，加玄参、知母各四钱，数剂痊愈。
一媪，年六旬，素多疾病。于夏季晨起，偶下白痢，至暮十余次。秉烛后，忽然浑身大热，不省人事，循衣摸床，呼之不应。其脉洪而无力，肌肤之热烙指。知系气分热邪内陷，兼以年高阴虚，热甚则神明昏乱也。急用生石膏三两，野台参四钱，煎汤一大碗，徐徐温饮下，至夜半尽剂而醒，痢亦遂愈。诘朝煎渣再服，其病脱然。
一人，年五十余，于暑日痢而且泻，其泻与痢俱带红色，下腹紧疼，噤口不食。医治两旬，病势增重，精神昏愦，气息奄奄。诊其脉，细数无力，周身肌肤发热。询其心中，觉亦发热，知其证夹热。虽暑月，热蓄于内，外受暑热，两热相并，故神昏。是以不能用干姜、附子之辛热，亦不能用黄连、黄柏之苦寒。遂用生山药两半，滑石一两，生杭芍六钱，粉甘草三钱，一剂病皆见愈，可以进食。又服一剂全愈。此证用滑石不用石膏者，以其证兼泻也。为不用石膏，恐不敢用凉药，故倍用山药以养阴，佐以芍药、甘草、滑石，甘寒淡渗，清热利湿而不伤正也。
