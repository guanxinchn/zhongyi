# 术语词典 · 《御纂醫宗金鑑》

> 每条均标注可核验出处 `S<册>-P<页>`。释义为便于 agent 使用的白话重写，**不是原文**；引用时必须回查原文。
> 「与常识差异」列用于防止用现代中医教材的通行义覆盖本书用法。

| 术语 | 本书用法（释义） | 原文出处 | 与常识用法的差异 |
|---|---|---|---|
| **心法** | 每论一证，必就阴阳、表里、寒热、虚实八项逐一反复辨析的程序；书名「○○心法要訣」即指此 | `S01-P25` | 常被误解为「口诀／秘诀」；本书指的是**辨析程序**，歌诀只是记忆外壳 |
| **要訣** | 分科卷名（四診、傷寒、雜病、婦科、幼科、痘疹、外科、眼科、刺灸），体裁为四言／七言韵文歌诀 + 低格注文 | `S25-P01`、`S25-P03` | 不是「简明摘要」，是可背诵的韵文 + 注 |
| **要旨** | 仅用于《幼科種痘心法要旨》《正骨心法要旨》，重手法、器具、图谱、分寸 | `S01-P48`（總目卷九十） | 与「要訣」的歌诀体有别 |
| **陰陽表裏寒熱虛實（八者）** | 「證候傳變難以言盡，而其要不外……八者而已」；八项是必过的检查项 | `S01-P25` | 现代常作「八纲辨证」知识点；本书作**每证必执行的检查清单**，且未给权重 |
| **執方昧法** | 只照搬成方而不求立方之意，被列为失败模式 | `S01-P21`–`S01-P22` | 不是「不会用方」，而是「不求其精意」 |
| **方者一定之法，法者不定之方** | 方是「法」的一次性固化；用方须还原立方所针对的病机 | `S01-P21` | 强调法的可迁移性高于方的固定性 |
| **順／險／逆** | 痘疹三候：順證不藥而愈、險證非藥不愈、逆證雖藥無濟 | `S01-P23` | 含预后与可治性分层，非单纯轻重分级 |
| **正誤／存疑** | 经文错简遗误者「詳於本條經文之下」；文义绝难意解者不强解，另彙「正誤」「存疑」二帙附卷末備考 | `S02-P03` | **本书自设的不确定处理机制**：读不通就标存疑，不硬解、不补写 |
| **據經訂正** | 以《内经》为准绳剔除臆说；凡例斥眼科「八廓則憑臆立論」，故「採輯諸書精蘊，棄其駁雜」 | `S01-P24` | 「折衷群书」不等于兼收并蓄，有明确的取舍判据 |
| **內外一體** | 「醫固無內外之可分」「無外之非本於內」；外科仍归脏腑气血、阴阳虚实、六淫七情 | `S01-P25` | 外科不独立成病机体系 |
| **神聖工巧** | 望＝神、聞＝聖、問＝工、切＝巧；「明斯診道，識病根源，能合色脈，可以萬全」 | `S25-P03`、`S01-P22` | 四诊有明确分工，且强调**互相參合**，不可偏取切脉 |
| **能合色脈** | 色诊与脉诊相合方可「萬全」 | `S25-P03`、`S01-P22` | 单凭脉或单凭色不足以定论 |
| **主色／客色** | 主色＝藏气所生、百岁不变；客色＝四时岁气加临、推迁不常；「客勝主善，主勝客惡」 | `S25-P05` | 读色须分常与变，不可见色即断病 |
| **但見一二證即是，不必悉具** | 桂枝汤方论：不必等主证齐备，见一二主证即可用 | `S23-P05` | 与「辨证须完整」不矛盾——指**方证对应**的抓主证，非省略八纲辨析 |
| **溫覆取汗** | 服桂枝汤须啜热稀粥、温覆令一时许、遍身漐漐微似有汗；「不可令如水流漓，病必不除」 | `S02-P08`、`S23-P08` | 汗法有严格的度；麻黄汤「峻與不峻在溫覆與不溫覆」 |
| **註／集註／按／解** | 注疏层次标识：经文大字 → 註 → 集註（诸家）→ 按（编纂者按语）→ 解（方解） | `S02-P05`、`S02-P08`、`S20-P05` | 引用时须区分「经文」「注文」「编纂者按语」，不可混作仲景原文 |
| **刪補名醫方論** | 「博集金匱千金外臺諸書及王好古李杲劉完素朱震亨張從政薛□諸方之佳者，採錄成編」；方论重在阐发立方之意 | `S20-P03` | 不是方剂汇编，是「方 + 诸家方论」的评选 |
| **五輪／八廓** | 眼科旧说；本书取五輪（本于经）而斥八廓（憑臆立論） | `S01-P24` | 同一分科内部亦有可信度分级 |
| **六淫七情** | 病因纲目，外科亦须「內以察其藏府氣血與夫陰陽虛實六淫七情病因」 | `S01-P25` | 内外各科共用同一病因框架 |

## 新增术语（多经典，2026-11-18）

> 溯源编号 `<书代码>-P<页>`；金鉴条目沿用 `S<册>-P<页>`。讲解本条目已标注。

| 术语 | 出处用法（释义） | 原文出处 | 与常识用法的差异 |
|---|---|---|---|
| **六经提纲** | 太阳"脉浮头项强痛而恶寒"、阳明"胃家实"、少阳"口苦咽干目眩"、太阴"腹满而吐食不下自利益甚"、少阴"脉微细但欲寐"、厥阴"消渴气上撞心"——每经一组最少症状锁定核心病机 | `SH-P079/151/175/178/179/194` | 是"辨病位+病性"的提纲证，非六个静态病名 |
| **传经／再传／过经** | 一日太阳…六日厥阴为传经尽，七日愈；不愈再传；十三日不愈为过经 | `SH-P027` | 注文强调以脉证为准，非死扣天数 |
| **阴病见阳脉者生** | 阴证见浮大数动滑等阳脉，提示邪由里出表、可汗而解；反之主死 | `SH-P026`、`WB-P145` | 是预后判据，不是单纯寒热属性 |
| **从类化** | 同一邪气因形藏虚实不同，可从寒化、热化、虚化、实化 | `S27-P05` | 病机不可由病名套用，须在具体人身上重推 |
| **二十七脉** | 濒湖脉学浮沉迟数滑涩虚实等27脉，各立体状诗/相类诗/主病诗 | `BH-P015`–`BH-P041` | 每脉三层结构：定形、辨似、主病 |
| **相类诗** | 辨相似脉：浮大中空为芤、拍拍而浮是洪、浮而柔细为濡、散似杨花 | `BH-P015` | 专为防脉象混淆而设 |
| **浮数风热／浮紧风寒** | 配伍脉定因：单脉定病位（浮=表），配伍脉定具体病因 | `BH-P016` | "浮"只说表，须靠配伍细分病因 |
| **寸关尺** | 寸/关/尺分部主不同脏腑：寸浮头痛风痰、关浮土衰木旺、尺浮溲便不利 | `BH-P016` | 同一脉在不同部位主病不同 |
| **脉乃四诊之末** | 李时珍自序：脉为四诊之末、谓之巧，上士会其全非备四诊不可 | `BH-P014` | 明确反对孤立凭脉断病，与金鉴"能合色脉"互证 |
| **苔色示邪深浅** | 白胎（邪在皮毛/半表半里）→黄胎（邪已深化热）→黑胎（热极或阴寒，危候） | `ST-P004`、`ST-P015` | 苔色是邪气进退的动态指标，非静态快照 |
| **黑胎燥润之别** | 黑胎燥者为热极宜下，润者（黑而滑润）为阴寒宜温，慎勿误下 | `ST-P015` | 同象异治，最容易误治的诊断陷阱 |
| **凡病温者始于上焦在手太阴** | 温病由口鼻入、自上而下、始手太阴肺；伤寒由毛窍入、自下而上、始足太阳 | `WB-P031` | 伤寒温病的根本分野：寒邪伤阳/温邪伤阴 |
| **证同而脉异** | 同为阳明温病，脉浮洪躁甚用白虎、脉沉数有力用承气；"脉浮者不可下" | `WB-P077` | 同一证候，脉象决定治法方向 |
| **诸方之禁** | 温病下焦：壮火尚盛不用定风珠/复脉，邪少虚多不用黄连阿胶汤，阴虚欲痉不用青蒿鳖甲汤 | `WB-P145` | "补阴/搜邪/护阳"三方有别，不可混用 |
| **大虚有盛候，大实有羸状** | 虚实真假：极度虚反见亢盛假象，极度实反见羸弱假象 | `NJS-P041`（讲解本） | 表象可欺，不可凭单一外象定虚实 |
| **精气夺则虚／邪气盛则实** | 虚=正气不足，实=邪气有余；寒热=阴阳偏盛偏衰 | `NJS-P041`（讲解本） | 八纲中寒热虚实的机理层解释 |
| **肝藏血，开窍于目，主筋** | 肝血虚则视力减退、四肢运动障碍；人卧血归于肝 | `NJS-P218`（讲解本） | 为"目/筋/四肢"症状归肝提供链条 |
| **方证锚定** | 张锡纯每方先列"治……"主治证候群作为选用入口条件 | `ZX-P021`、`ZX-P023` | 方证对应+全程加减+用药心法的医案范式 |
| **裂纹舌（舌体）** | 舌面裂沟，总主阴血亏虚；红绛少苔燥裂属热盛伤阴，浅淡属血虚，细碎常见于年老阴虚 | `MOD-CM9-04`、`MOD-SAT-01/02/03` | 现代权威层，非古籍`ST-*`舌苔层；舌色定寒热，不单值等于阴虚 |
| **齿痕舌（齿印）** | 舌边齿痕，主脾虚水湿内停；淡红嫩属脾虚，淡白湿润属寒湿/阳虚水湿内停 | `MOD-CM9-05`、`MOD-SAT-04` | 现代权威层；须合舌色苔质定寒热 |
| **裂纹＋齿痕并见（脾虚湿侵）** | 舌淡白胖嫩、边有齿痕又兼裂纹，为脾虚湿侵；须以"淡白胖嫩"为前提，否则存疑 | `MOD-SAT-03` | 现代权威层专条；可参与辨证但须随行出处，不据此开方 |
| **老嫩／胖瘦舌** | 老舌主实证热证、嫩舌（浮胖或边齿痕）主虚证寒证；胖肿主脾虚湿蕴、瘦瘪主气血虚或阴虚 | `MOD-CM9-01`、`MOD-CM9-02` | 现代权威层，`MOD-CM9-01`为齿痕属虚提供独立依据 |
