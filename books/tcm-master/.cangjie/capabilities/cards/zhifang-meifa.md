# CAP-04 先法后方与方证对应（戒執方昧法）

> capability_id: CAP-04 ｜ 重要度: high ｜ 来源: 首卷凡例、卷二十六／三十一《刪補名醫方論》

## R — 原文（Reading）

> 方者一定之法法者不定之方也古人之方即古人之法寓焉立一方必有一方之精意
>
> — 首卷凡例葉一，`S01-P21`

> 存於其中不求其精意而徒執其方是執方而昧法也
>
> — 首卷凡例葉二，`S01-P22`

> 此方爲仲景羣方之冠乃解肌發汗調和營衞之第一方也凡中風傷寒脈浮弱汗自出而表不解者皆得而主之其他但見一二證即是不必悉具
>
> — 卷三十一《刪補名醫方論卷六》桂枝湯方論，`S23-P05`

> 是知麻黃湯之峻與不峻在溫覆與不溫覆此仲景用方之心法豈常人所能得而窺耶
>
> — 卷三十一《刪補名醫方論卷六》麻黃湯方論，`S23-P08`

## I — 方法论骨架（Interpretation）

本书的方论观是：**方是「法」的一次性固化，法才是可迁移的东西**。「立一方必有一方之精意」——每一首方背后都有一条针对特定病机的立法意图；只照搬方名药物而不还原这条意图，就是「執方而昧法」，被凡例列为明确的失败模式。

因此用方顺序是：先由八纲与病机定「法」（解肌、温散、调和营卫……），再找与该法对应的方；不是反过来由病名直接套方。

两个重要的操作细则：
- **抓主证，不必悉具**：「但見一二證即是，不必悉具」（`S23-P05`）。方证对应看主证，不等全部症状齐备。
- **服法即法的一部分**：麻黄汤「峻與不峻在溫覆與不溫覆」（`S23-P08`），桂枝汤须「啜熱稀粥、溫覆令一時許、遍身漐漐微似有汗，不可令如水流漓」（`S02-P08`）。脱离服法谈方，仍属昧法。

要区分：这与八纲「八项必过」不矛盾。八纲是辨析必须完整，抓主证是**方证对应阶段**的操作。

## A1 — 书中的应用（Past Application）

### 案例 1：桂枝汤的方证扩展与界限（`S23-P05`）
方论明言桂枝汤为「解肌發汗調和營衞之第一方」；指出「粗工妄謂桂枝湯專治中風，不治傷寒，使人疑而不用」，又谓「專發肌表，不治他病」亦是误解；并列举倍芍药生姜加人参为桂枝新加汤、倍芍药加饴糖（接下页）等加减。
→ 同一「法」可通过加减化裁覆盖不同证，正是「法者不定之方」。

### 案例 2：汗后、下后的方证转换（`S23-P05`）
「初起無汗當用麻黃發汗，如汗解後復□脈浮數者，與下後脈仍浮氣上衝者……皆用此以解外」，理由是「表雖不解，腠理已疏，邪不在皮毛而在肌肉，且經汗下津液已傷，故脈證雖同麻黃而主治當屬桂枝」。
→ 病位与津液状态变了，法随之变，方随之换；不是见「表不解」就固守一方。

### 案例 3：温覆决定麻黄汤之峻（`S23-P08`）
方论列麻桂各半汤、桂枝二越婢一汤、麻杏甘石汤、麻黄附子细辛甘草汤等化裁，并归结「峻與不峻在溫覆與不溫覆」。
→ 服法与化裁都属「法」的范畴。

### 案例 4：删「去皮」二字（`S02-P08`）
编纂者按语据药性订正方中文字（「桂枝氣味辛甘全在於皮……宜删此二字，後倣此」）。
→ 连方中药物的炮制表述也要回到方义来判定。

## A2 — 触发场景（Future Trigger）

### 情境
1. 用户问「这个方对不对证」「为什么用这个方」。
2. 用户问「同样是表证，为什么有时用桂枝有时用麻黄」。
3. 用户问某方的加减、化裁思路。
4. 用户问「症状没齐能不能用」。

### 语言信号
- 「对证吗」「立方之意」「为什么用这个方」「抓主证」「加减」「化裁」「但见一证」
- 「执方昧法」「方证对应」「服法」「温覆」
- "formula matches", "why this prescription", "modification"

### 与相邻能力的区分
- 与 `fangji-suoyuan`：后者查方名、组成、出处；本卡判断**法与证是否相合**。
- 与 `bingji-tuiduan`：病机链由它出，本卡把病机接到方上。
- 与 `bazheng-tuigang`：八纲是前置步骤，不可跳过。
- 与 `anquan-bianjie`：一旦落到「我吃这个方、吃多少」，立即转它。

## E — 可执行步骤（Execution）

1. **先复述病机与八纲结论**
   - 引用 `bazheng-tuigang` / `bingji-tuiduan` 的结论，明确病位、病性、邪正。
   - 完成标准：能说出「当下需要什么法」。

2. **在语料中找对应方论**
   - 只从 `corpus/` 已转录的方论页取证，记 `Sxx-Pxx` + 卷次篇名。
   - 完成标准：找到方论原文（主治、方论、加减或服法之一）。
   - 判停条件：未转录 → 回答「该方论未转录，无可核验依据」，不凭记忆补。

3. **核对主证与禁忌**
   - 按「但見一二證即是，不必悉具」判断主证是否成立；**同时取回明文禁忌**（如 `S23-P03` 桂枝汤「脈浮緊汗不出者、酒客……禁用」）。
   - 完成标准：主治与禁忌成对出现，缺禁忌不算完成。

4. **说明「法」而非只报方**
   - 解释立方之意、加减化裁方向、服法要点（温覆、啜粥、不可如水流漓）。
   - 完成标准：回答中「法」的解释不少于「方」的罗列。

5. **输出与判停**
   - 固定四段：法与证是否相合 / 依据出处 / 禁忌与误治警示 / 安全提示。
   - 不给剂量、不折算克重、不建议自行服用 → 触发 `anquan-bianjie`。

## B — 边界（Boundary）

### 不要在以下情况使用
- 用户只要方名组成出处 → 转 `fangji-suoyuan`。
- 用户要求开方、剂量、自行服药 → 转 `anquan-bianjie`。
- 急危重症 → 转 `anquan-bianjie`。

### 书中警告的失败模式
- 「執方而昧法」（`S01-P22`）。
- 「粗工妄謂桂枝湯專治中風不治傷寒」（`S23-P05`）：把方与病名机械绑定。
- 「不溫覆取汗則不峻」（`S23-P08`）：忽略服法。
- 「尺中脈遲……不可發汗」（`S27-P08`）：不辨虚实而用汗法致变证。

### 盲点与时代局限
- 方论基于 18 世纪病机模型，无现代药理与循证支持。
- 「但見一二證即是」易被滥用为省略辨析；本技能只在**八纲已过一遍**后使用。
- 加减与化裁依书中文字，不引入后世方剂学内容。

### 容易混淆的邻近方法论
- 后世「方证对应」流派与本书「法–方」关系不同；不得混用其判定标准。
