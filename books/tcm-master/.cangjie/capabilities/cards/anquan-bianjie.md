## I — 方法论骨架（Interpretation）

《御纂醫宗金鑑》是 18 世纪官修医书，其价值在文献、思路与辨证程序，**不是可直接执行的现代诊疗方案**。本卡把这一判断变成可操作的判停规则。

三条硬约束：

1. **输出物是「本书怎么说、怎么辨」，不是「你该吃什么药」**。书中方剂可原文引录（含主治、组成、禁忌、服法），但不为具体个人开具处方。
2. **剂量不可折算**。书用清制兩、錢、分，且随季节、炮制、地域变化（如保元汤肉桂「春夏二三分，秋冬六七分」）。本技能不提供现代克重换算，不判断可否自行服用。
3. **书中自带禁忌与误治警示**，必须一并给出，不能只报主治不报禁忌（如桂枝汤明列「脈浮緊汗不出者」「酒客」禁用）。

阶段 0 批判结论在此生效：无对照观察、无统计、无不良事件记录，「折衷群书」属专家意见汇总，不构成疗效证据；运气学说、顺险逆预后分层不可作现代临床判断。

## A1 — 书中的应用（Past Application）

### 案例 1：桂枝汤的明文禁忌（`S23-P03`）
主治列「脈浮弱、自汗出、頭痛發熱、惡風惡寒、鼻鳴乾嘔」，随即明列「若脈浮緊汗不出者，酒客病風寒而汗出者禁用」。
→ 报方必须**主治与禁忌同报**，缺禁忌即为不完整引用。

### 案例 2：误汗变证（`S27-P08`）
注文载「尺中脈遲是營氣不足，不可發汗」，误发则「漏汗惡風、四肢拘急、小便難」；大青龙证「脈微弱、汗出」而误发，致「厥冷筋惕心悸頭眩、身內瞤動」。
→ 书中反复以变证警示：不辨虚实即施汗法有明确风险。

### 案例 3：清制剂量与季节加减（`S20-P08`）
保元汤「黃耆三錢、甘草一錢」，肉桂「春夏二三分，秋冬六七分」。
→ 剂量依时令浮动，进一步说明**不存在可直接照抄的固定克重**。

### 案例 4：预后分层（`S01-P23`）
痘疹「順／險／逆」三候及「逆證雖藥無濟」。
→ 这是 18 世纪对可治性的判断，不可用于现代患儿的处置决策，尤其不可据此建议「不就医」。

## A2 — 触发场景（Future Trigger）

### 情境
1. 用户要求「给个治疗方案」「开个方」「我该吃什么药」「吃多少」。
2. 用户问「能不能自己去抓药」「这个剂量换成克是多少」。
3. 描述中出现急危重症信号。
4. 涉及孕妇、婴幼儿、老人、慢病用药、有毒药物或外治手法。
5. 用户把古籍结论当作可以直接照做的医嘱。

### 语言信号
- 「怎么治」「吃什么药」「剂量」「几克」「煎服」「自己去买」「能不能停药」
- 「胸痛」「呼吸困难」「意识不清」「高热不退」「抽搐」「大出血」「剧烈腹痛」
- "treatment plan", "dosage", "should I take", "emergency"

### 与相邻能力的区分
- 与 `fangji-suoyuan`：查方剂组成主治可以继续，但**一旦落到「我用多少」立即转本卡**。
- 与 `bazheng-tuigang` / `bingji-tuiduan`：辨证与病机解释可继续，但不得输出可执行处方。
- 与 `zhengwu-cunyi`：本卡处理「能不能做」，引用纪律处理「有没有出处」，两者可同时生效。

## E — 可执行步骤（Execution）

1. **先扫描急危重症信号**
   - 出现意识改变、剧烈胸痛、呼吸困难、大出血、高热惊厥、剧烈腹痛、疑似卒中、严重外伤、孕产或新生儿急症等 → **立即停止一切辨证与查方**，优先提示尽快就医／急救。
   - 完成标准：安全提示位于回答最前，且不被后续内容冲淡。

2. **识别请求类型**
   - 文献解释／辨证思路 → 允许继续（转相应能力卡）。
   - 处方、剂量、克重换算、能否自行服药、停药改药 → 进入第 3 步判停。
   - 完成标准：明确分类，不打擦边球。

3. **执行判停并说明原因**
   - 固定说明：本书成书于 18 世纪，剂量用清制兩錢分且随季节炮制浮动，无现代药理毒理与循证依据；本技能只提供文献与思路，不提供诊疗方案。
   - 完成标准：不给出任何具体用量、不折算克重、不推荐自行服用。

4. **给出可继续的替代帮助**
   - 可提供：原文主治与禁忌（含出处）、辨证思路、需向医师补充哪些信息、书中相关的误治警示。
   - 完成标准：用户仍有可获得的、有出处的信息，而非被简单拒绝。

5. **目录式提示**
   - 提示「请携具体症状与检查结果，由执业中医师面诊决定」；不指定具体医院、药品或品牌。
   - 完成标准：回答结尾有明确、简短的就医提示。

## B — 边界（Boundary）

### 不要在以下情况使用
- 纯文献、纯考据、纯歌诀学习问题 → 不必触发本卡，避免每次回答都堆免责声明。
- 用户明确是学术／版本研究 → 按 `zhengwu-cunyi` 处理。

### 书中警告的失败模式
- 「執方而昧法」（`S01-P21`–`S01-P22`）：照搬成方而不求立方之意。
- 「粗工妄謂桂枝湯專治中風不治傷寒，使人疑而不用」（`S23-P05`）：机械套方。
- 「尺中脈遲……不可發汗」（`S27-P08`）：不辨虚实而误汗致变。
- 「勉加註釋，終屬牽强」（`S02-P03`）：不确定处强行给结论。

### 盲点与时代局限（阶段 0 批判）
- 无现代解剖、生理、病理、微生物学与药理毒理；脏腑经络、六淫七情为当时解释模型。
- 运气学说（卷三十五）含天人相应预设，不能作流行病学或个体诊断依据。
- 部分外治、痘疹、正骨手法与药物按今日标准存在风险。
- 「順證不藥而愈、逆證雖藥無濟」的预后分层不可用于现代临床决策。
- 官修「折衷羣書、定于一尊」压制异说；以《灵素》《伤寒》《金匮》为不可疑前提。
- **最强反对意见**：全部结论来自经典权威与专家共识，无对照观察、无统计、无不良事件记录，不构成疗效证据。

### 容易混淆的邻近方法论
- 「列出原文中的方剂与主治」≠「推荐用药」；前者是文献检索，后者是医疗建议。
- 「解释病机」≠「作出诊断」；本书语境下的「证」不等于现代疾病诊断。
