# CAP-18 方证医案推演（医学衷中参西录）

> capability_id: CAP-18 ｜ 重要度: high ｜ 来源: 《医学衷中参西录》（张锡纯，前三期合编）
> 这是贴近"根据描述判定病因 + 提出真实可行方案 + 列依据"用户诉求的近代医案能力，但**输出为文献医案思路，不构成处方**。

## R — 原文（Reading）

> 资生汤：治劳瘵羸弱已甚，饮食减少，喘促咳嗽，身热脉虚数者。亦治女子血枯不月。生山药一两，玄参五钱，于术三钱，生鸡内金二钱（捣细），牛蒡子三钱（炒，捣）。热甚者，加生地黄五六钱。
>
> — 前三期合编第一卷·治阴虚劳热方，`ZX-P021`

> 民国二年，客居大名。治一室女，劳瘵年余，月信不见，羸弱不起。询方于愚，为拟此汤。连服数剂，饮食增多。身犹发热，加生地黄五钱，五六剂后，热退渐能起床，而腿疼不能行动。又加丹参、当归各三钱，服至十剂腿愈，月信亦见。
>

> 十全育真汤：治虚劳，脉弦数细微，肌肤甲错，形体羸瘦，饮食不壮筋力，或自汗，或咳逆，或喘促，或寒热不时，或多梦纷纭，精气不固。
>
> — 第一卷·十全育真汤，`ZX-P023`

>
> — 第二卷·赭石论，`ZX-P037`

## I — 方法论骨架（Interpretation）

张锡纯医案提供一套**"方证对应 + 全程加减"的推演范式**，每条医案都是完整的临床推理链：

1. **方证锚定**：每方先列"治……"的主治证候群（如资生汤治"劳瘵羸弱、饮食减少、喘促咳嗽、身热脉虚数"），这是选用该方的入口条件。
2. **症状-加减映射**：主方确定后，随症加减有明确规则（热甚加生地、腿疼加丹参当归、白带甚去丹参加牡蛎倍于术、气分虚甚去三棱莪术加鸡内金）——体现"方者一定之法，法者不定之方"（与金鉴 `S01-P21` 互证）。
3. **全程动态追踪**：医案记录服药后的病情演变与随证调整（数剂→饮食增多→热退→腿疼→加味→痊愈），展示辨证不是一次性的，而是随疗效反馈迭代。
4. **用药心法与依据**：张锡纯自述为何放胆用重剂（赭石一两至二两）、为何佐人参、为何生用山药（炒熟分毫无效），把"为什么这样用"讲清楚。

独特价值：这是**近代医案**，比古籍更接近"症状描述→辨证→方案"的真实诊疗记录，最适合回答"根据这段描述怎么辨、思路是什么"。但张锡纯中西汇通（如"西人谓地黄含铁质""地黄以铁补铁"）属时代认识，须标注为作者观点，不作现代药理结论。

## A1 — 书中的应用（Past Application）

### 案例 1：室女劳瘵的完整推演（`ZX-P023`）
室女劳瘵年余、月信不见、羸弱不起 → 拟资生汤 → 饮食增多但身热 → 加生地 → 热退能起床但腿疼 → 加丹参当归 → 腿愈月信见 → 又述白带甚 → 去丹参加牡蛎、倍于术 → 带证愈。一案之中四次随证转方，是"方证对应 + 动态加减"的教科书式链条。

### 案例 2：十全育真汤的方证锁定（`ZX-P023`）
"脉弦数细微，肌肤甲错，形体羸瘦，饮食不壮筋力，或自汗，或咳逆，或喘促，或寒热不时，或多梦纷纭，精气不固"——用一组症状+脉象锁定虚劳方证，并列三条加减法（气分虚、喘促、汗多各不同）。

### 案例 3：赭石救危的用药依据（`ZX-P037`）
妊娠呕吐结闭（"有故无殒亦无殒"）、胸次郁结、上焦满闷、呃逆小便不通——多则医案支撑"赭石为救颠扶危之大药"，并自述重用依据："临证既久，研究数十年，心中皆有定见，而后敢如此放胆"。

## A2 — 触发场景（Future Trigger）

### 情境
1. 用户给出一段较详细的症状描述，问"这像什么证、思路是什么、有哪些方证可参考"。
2. 用户问"张锡纯怎么治这个""有没有相关医案"。
3. 用户问"某个方（资生汤/十全育真汤等）治什么、怎么加减"。
4. 用户想看"真实的辨证-'处方'思路链"（作为学习，非自用）。

### 语言信号
- 「张锡纯」「衷中参西录」「资生汤」「十全育真汤」「赭石」「薯蓣」
- 「医案」「这个症状怎么治」「思路是什么」"case"
- "有没有类似病案""怎么加减"

### 与相邻能力的区分
- 与 `fangji-suoyuan`（CAP-05）：方剂溯源卡查组成出处，本卡给**完整医案的辨证-用方-加减链**。
- 与 `bingji-tuiduan`（CAP-03）：病机卡解释机理，本卡展示真实医案中的决策过程。
- 与 `zhifang-meifa`（CAP-04）：都强调"法高于方"，本卡以医案呈现动态转方。

## E — 可执行步骤（Execution）

1. **提取方证锚点**：从用户描述中找出与某方主治证候群（"治……"）吻合的症状与脉象。
2. **匹配医案**：在语料中找相似医案，标 `ZX-P<页>` 与原书页；说明相似点与差异点。
3. **梳理加减规则**：列出主方与该证型的随症加减（如热甚加生地）。
4. **呈现推理链**：按"症状→辨证→选方→加减→转归"组织，每条附出处。
5. **强制安全声明**：明确这是近代医案文献，**不构成对用户本人的处方**；剂量原样照录、不可自行折算；有用药或急症诉求转 `anquan-bianjie`。
6. **标注时代局限**：中西汇通论述（如地黄含铁）标明为作者时代观点。

## B — 边界（Boundary）

### 不要在以下情况使用
- 用户要求"给我开这个方、告诉我吃多少" → 转 `anquan-bianjie`，只作文献介绍。
- 急危重症、孕产新生儿 → 立即提示就医（医案中的妊娠案是文献，非可复制方案）。
- 把医案剂量当作现代推荐量 → 明确禁止。

### 书中警告的失败模式
- 张锡纯批"今人罕用（赭石），间有用者不过二三钱，药不胜病，用与不用同"——但这是他放胆用重剂的个人经验，建立在"研究数十年"基础上，**不可被初学者机械模仿**。
- 资生汤强调山药"若用炒熟则分毫无效"——用药细节须尊重原书，不可随意替换。

### 盲点与时代局限
- 医案为个人经验，无对照与统计，疗效描述可能含个案偏倚。
- 中西汇通论述（地黄含铁、脑部思等）是 19 末20 世纪初的认识，非现代药理/神经科学结论。
- 剂量用旧制（两、钱），不可自行折算服用。
