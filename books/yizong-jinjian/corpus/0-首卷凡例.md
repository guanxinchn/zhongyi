## S01-P21｜首卷凡例 葉一

```
御纂醫宗金鑑首卷
凡例
一 醫書自靈素而後惟漢張機傷寒論金匱要畧二書實一脈相承但義理淵深方法微奧
  領會不易且多譌錯舊註隨文附會難以傳信今於其錯譌者悉為訂正逐條詳加註釋
  更集諸註之實足闡發微義者以備叅考
一 方者一定之法法者不定之方也古人之方即古人之法寓焉立一方必有一方之精意 ‖
```
> 右半叶为空白；左半叶起凡例。此叶确立全书编纂原则：**訂正譌錯、詳加註釋、薈萃諸註**。
> 「方者一定之法，法者不定之方」为全书方论观的总纲。

## S01-P22｜首卷凡例 葉二

```
‖ 存於其中不求其精意而徒執其方是執方而昧法也舊有醫方考醫方解等書尚未能
  暢發前人之精意今於各書中能透發古方之精意者萃而集之不當者刪之未備者補之
一 天時之不齊民病所由生也素問言五運六氣特詳醫不明此則不識亢害承制淫勝鬱
  復之理不足以稱醫之良也但經文散見諸篇學者每有望洋之嘆今搜集成編俾一覽
  無遺庶易於融會貫通
一 望聞問切古聖稱為聖神工巧蓋醫者之首務也經云能合色脈可以萬全又云聞其聲
  而知其人之疾苦問其苦欲而知其病之所在是雖聖人不能舍此以為法也而況後學
  乎今取崔紫虛四言脈訣上合靈素之言望聞問切者集為一編學者熟讀玩味臨證之
  時自有得心應手之妙
一 婦科諸證與方脈無異惟經帶崩漏胎產癥 ‖
```
> **「執方而昧法」之戒**：不可只执成方而不求立方之意。
> **四诊为医者首务**，明确「合色脈」「聞其聲」「問其苦欲」；四診心法要訣（卷三十四）由此立。
> 運氣要訣（卷三十五）由此立，理由为「天時之不齊，民病所由生」。

## S01-P23｜首卷凡例 葉三

```
‖ □□不同茲集於此數證折衷羣書詳加探討病情方藥要歸正當其他諸證與方脈同者
  仍當於雜證門求之
一 嬰兒氣血未充形神怯弱藏府柔脆風痰驚食諸邪易乘難去故急則為驚緩則成疳即
  吐瀉感冒等證治之稍不如法皆足變生不測前賢稱為難醫不誠然哉非理明心細識
  精膽大未易擅場茲分門別類博採羣書撮其精粹以為幼科指南
一 痘疹亦嬰兒之一證也而必耑其科者以其傳變迅速猶方脈之傷寒不可以時日待也
  雖然治痘誠難而得其要旨則難者易矣蓋痘自稟賦天時人事以及發熱見點起脹灌
  漿結痂落痂莫不有順險逆之三候順證不藥而愈險證非藥不愈逆證雖藥無濟業是
  科者能於此辨之明審之確更詳察其虛實寒熱所兼所挾之證而治之則於以挽回造
  化也無難矣疹證雖有數種惟麻疹一證變 ‖
```
> 儿科立法依据：「氣血未充、形神怯弱、藏府柔脆」，故「急則為驚，緩則成疳」。
> 痘疹设专科的理由：**傳變迅速，猶方脈之傷寒**；并提出**順／險／逆三候**与「詳察虛實寒熱所兼所挾」的辨证要求。

## S01-P24｜首卷凡例 葉四

```
‖ 幻莫測更宜詳究若夫種痘一法則又去逆就順化險為平欲以人定勝天者也自宋以
  後始有是法皆互相授受未有成書今取耑科世業屢經試驗方法載之於書
一 眼科自靈樞大惑篇數語已足該後世五輪八廓之義千金外臺又演其旨銀海精微列
  證百餘條龍木論分為五輪八廓內障外障七十二證宋金元明諸賢著述各有發明可
  謂既詳且盡矣然五輪之說尚本於經而八廓則憑臆立論三因病情未見精切茲特據
  經訂正採輯諸書精蘊棄其駁雜
一 靈樞經為刺灸家鼻祖其文精微詳盡銅人一圖星羅棋布甲乙千金等書闡其意旨然
  精斯術者恒不易得何也誠以經脈流行交會支別過接之際與夫井滎俞經合原等穴
  毫釐一差千里遂謬非窮究博考口傳心授鮮能得其奧旨近世惟天星奇穴猶有得其
  傳者其他未之嘗聞今取靈樞各家之書精 ‖
```
> 眼科明确批评「八廓則憑臆立論」，主张**據經訂正、棄其駁雜**——全书对无据之说的态度。
> 刺灸强调穴位分寸「毫釐一差，千里遂謬」，故须**繪圖立說**。

## S01-P25｜首卷凡例 葉五 ★核心

```
‖ 研詳究考其分寸明其行列一一繪圖立說
一 人身藏府根於內經絡行於外氣血流貫於其中醫固無內外之可分也苐以證之形於
  外故稱之曰外科經云六府不和留結為癰亦可知無外之非本於內矣是集繪圖立說
  外以辨其形色部位經絡內以察其藏府氣血與夫陰陽虛實六淫七情病因方藥內治
  外治諸法詳載於篇
一 正骨科向無成書各家著述惟準繩稍備然亦只言其證藥而於經絡部位骨度名目手
  法俱未嘗詳言之今考靈素骨度篇及十二經絡與所傷部位及外治內治藥餌手法器
  具一一繪圖立說彙集成書
一 證候傳變難以言盡而其要不外陰陽表裏寒熱虛實八者而已是集凡論一證必於是
  八者反覆詳辨故謂之心法經云知其要者一言而終不知其要流散無窮此之謂歟
一 醫者書不熟則理不明理不明則識不精臨 ‖
```

### CORE-01｜八纲辨证总纲（全书最高级依据）

原文（`S01-P25`，卷首凡例葉五）：

> 證候傳變難以言盡而其要不外**陰陽表裏寒熱虛實**八者而已是集凡論一證必於是八者反覆詳辨故謂之心法

释义（供能力卡使用，非原文）：证候传变难以穷尽，但提纲不出**阴阳、表里、寒热、虚实**八项；本书每论一证，必就此八项反复辨析，故称「心法」。

**由此确立全书辨证推演的固定顺序**：
1. 先定**阴阳**（总纲）
2. 次定**表里**（病位）
3. 次定**寒热**（病性）
4. 次定**虚实**（邪正）
5. 八项辨明后，再论**病因**（六淫、七情）、**脏腑经络**、**治法方药**
6. 外科亦不例外：「外以辨其形色部位經絡，內以察其藏府氣血與夫陰陽虛實六淫七情病因」

### CORE-02｜内外一体观

> 人身藏府根於內經絡行於外氣血流貫於其中醫固無內外之可分也……亦可知無外之非本於內矣（`S01-P25`）

外科疮疡虽形于外，仍须从脏腑气血、阴阳虚实、六淫七情求其内因。
