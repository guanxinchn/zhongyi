# 术语词典 · 《御纂醫宗金鑑》

> 每条均标注可核验出处 `S<册>-P<页>`。释义为便于 agent 使用的白话重写，**不是原文**；引用时必须回查原文。
> 「与常识差异」列用于防止用现代中医教材的通行义覆盖本书用法。

| 术语 | 本书用法（释义） | 原文出处 | 与常识用法的差异 |
|---|---|---|---|
| **心法** | 每论一证，必就阴阳、表里、寒热、虚实八项逐一反复辨析的程序；书名「○○心法要訣」即指此 | `S01-P25` | 常被误解为「口诀／秘诀」；本书指的是**辨析程序**，歌诀只是记忆外壳 |
| **要訣** | 分科卷名（四診、傷寒、雜病、婦科、幼科、痘疹、外科、眼科、刺灸），体裁为四言／七言韵文歌诀 + 低格注文 | `S25-P01`、`S25-P03` | 不是「简明摘要」，是可背诵的韵文 + 注 |
| **要旨** | 仅用于《幼科種痘心法要旨》《正骨心法要旨》，重手法、器具、图谱、分寸 | `S01-P48`（總目卷九十） | 与「要訣」的歌诀体有别 |
| **陰陽表裏寒熱虛實（八者）** | 「證候傳變難以言盡，而其要不外……八者而已」；八项是必过的检查项 | `S01-P25` | 现代常作「八纲辨证」知识点；本书作**每证必执行的检查清单**，且未给权重 |
| **執方昧法** | 只照搬成方而不求立方之意，被列为失败模式 | `S01-P21`–`S01-P22` | 不是「不会用方」，而是「不求其精意」 |
| **方者一定之法，法者不定之方** | 方是「法」的一次性固化；用方须还原立方所针对的病机 | `S01-P21` | 强调法的可迁移性高于方的固定性 |
| **順／險／逆** | 痘疹三候：順證不藥而愈、險證非藥不愈、逆證雖藥無濟 | `S01-P23` | 含预后与可治性分层，非单纯轻重分级 |
| **正誤／存疑** | 经文错简遗误者「詳於本條經文之下」；文义绝难意解者不强解，另彙「正誤」「存疑」二帙附卷末備考 | `S02-P03` | **本书自设的不确定处理机制**：读不通就标存疑，不硬解、不补写 |
| **據經訂正** | 以《内经》为准绳剔除臆说；凡例斥眼科「八廓則憑臆立論」，故「採輯諸書精蘊，棄其駁雜」 | `S01-P24` | 「折衷群书」不等于兼收并蓄，有明确的取舍判据 |
| **內外一體** | 「醫固無內外之可分」「無外之非本於內」；外科仍归脏腑气血、阴阳虚实、六淫七情 | `S01-P25` | 外科不独立成病机体系 |
| **神聖工巧** | 望＝神、聞＝聖、問＝工、切＝巧；「明斯診道，識病根源，能合色脈，可以萬全」 | `S25-P03`、`S01-P22` | 四诊有明确分工，且强调**互相參合**，不可偏取切脉 |
| **能合色脈** | 色诊与脉诊相合方可「萬全」 | `S25-P03`、`S01-P22` | 单凭脉或单凭色不足以定论 |
| **主色／客色** | 主色＝藏气所生、百岁不变；客色＝四时岁气加临、推迁不常；「客勝主善，主勝客惡」 | `S25-P05` | 读色须分常与变，不可见色即断病 |
| **但見一二證即是，不必悉具** | 桂枝汤方论：不必等主证齐备，见一二主证即可用 | `S23-P05` | 与「辨证须完整」不矛盾——指**方证对应**的抓主证，非省略八纲辨析 |
| **溫覆取汗** | 服桂枝汤须啜热稀粥、温覆令一时许、遍身漐漐微似有汗；「不可令如水流漓，病必不除」 | `S02-P08`、`S23-P08` | 汗法有严格的度；麻黄汤「峻與不峻在溫覆與不溫覆」 |
| **註／集註／按／解** | 注疏层次标识：经文大字 → 註 → 集註（诸家）→ 按（编纂者按语）→ 解（方解） | `S02-P05`、`S02-P08`、`S20-P05` | 引用时须区分「经文」「注文」「编纂者按语」，不可混作仲景原文 |
| **刪補名醫方論** | 「博集金匱千金外臺諸書及王好古李杲劉完素朱震亨張從政薛□諸方之佳者，採錄成編」；方论重在阐发立方之意 | `S20-P03` | 不是方剂汇编，是「方 + 诸家方论」的评选 |
| **五輪／八廓** | 眼科旧说；本书取五輪（本于经）而斥八廓（憑臆立論） | `S01-P24` | 同一分科内部亦有可信度分级 |
| **六淫七情** | 病因纲目，外科亦须「內以察其藏府氣血與夫陰陽虛實六淫七情病因」 | `S01-P25` | 内外各科共用同一病因框架 |
