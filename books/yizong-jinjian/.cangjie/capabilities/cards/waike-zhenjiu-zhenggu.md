# CAP-10 外科内外一体与刺灸正骨分寸

> capability_id: CAP-10 ｜ 重要度: medium ｜ 来源: 首卷凡例、卷六十一／六十五／七十一《外科心法要訣》、卷七十八《眼科心法要訣》、卷七十九／八十《刺灸心法要訣》、卷八十九《正骨心法要旨》

## R — 原文（Reading）

> 人身藏府根於內經絡行於外氣血流貫於其中醫固無內外之可分也苐以證之形於外故稱之曰外科……外以辨其形色部位經絡內以察其藏府氣血與夫陰陽虛實六淫七情病因方藥內治外治諸法詳載於篇
>
> — 首卷凡例葉五，`S01-P25`

> 誠以經脈流行交會支別過接之際與夫井滎俞經合原等穴毫釐一差千里遂謬……今取靈樞各家之書精研詳究考其分寸明其行列一一繪圖立說
>
> — 首卷凡例葉四（跨 p24–p25），`S01-P24`、`S01-P25`

> 胸骨即髃骬骨乃胸脇眾骨之統名也一名膺骨一名臆骨俗名胸膛其兩側自腋而下至肋骨之盡處統名曰脇……凡胸骨被物從前面撞打跌仆者重從後面撞仆者輕
>
> — 卷八十九《編輯正骨心法要旨》「胸骨」條，`S60-P05`

> 頭／註頭者人之首也凡物獨出之首皆名曰頭　腦／註腦者頭骨之髓也俗名腦子　顛／註顛者頭頂也　囟／註囟者顛前之頭骨也小兒初生未闔名曰囟
>
> — 卷八十《編輯刺灸心法要訣》「周身名位骨度」，`S59-P05`

## I — 方法论骨架（Interpretation）

四个分科共用一条总原则：**内外一体**。凡例明言「醫固無內外之可分」，外科虽形于外，仍要「內以察其藏府氣血與夫陰陽虛實六淫七情病因」——所以外科不是另一套病机体系，只是入口从形色部位经络开始。

第二条是**分寸与图谱**：刺灸因「毫釐一差，千里遂謬」，正骨因「經絡部位骨度名目手法俱未嘗詳言」，故本书「一一繪圖立說」。本次转录的图中，穴位／部位小字多漫漶不可辨，转写员**如实未录**——这是重要边界：图只可作版式与名目依据，不可作穴位定位依据。

第三条是**可信度分级**：眼科「五輪之說尚本於經，而八廓則憑臆立論……茲特據經訂正，採輯諸書精蘊，棄其駁雜」（`S01-P24`）。同一分科内部也要区分本于经与臆说。

正骨条文的体例是：部位名目 → 别名与俗名 → 受伤机制与轻重 → 手法／内外治法 → 方药。读时先定部位，再谈处置。

## A1 — 书中的应用（Past Application）

### 案例 1：外科卷以经络部位起首（`S43-P01/P02/P03`）
卷六十一目录含「十二經循行部位歌」及诸灸法歌；正文起首即经络循行。另有「頭前正面圖」（`S43-P05`）、「胸腹圖」（`S43-P08`）、「三里發圖」（`S52-P03`）等插图。
→ 外科先定位经络部位，再论疮疡，正合凡例「外以辨其形色部位經絡」。

### 案例 2：骨度名目逐条训释（`S59-P05`、`S59-P08`）
卷八十「周身名位骨度」以「頭、腦、顛、囟、鼻、頄、顴、耳、蔽、耳郭、頰」等部位名为大字，下附双行注文（如「囟者顛前之頭骨也，小兒初生未闔名曰囟」）。
→ 分寸之学先正名，名不正则定位无从谈起；注文用俗名对照，便于指认。

### 案例 3：正骨胸骨条的完整层次（`S60-P05`）
先释名（髃骬骨、膺骨、臆骨、胸膛），次释胁、季胁、肋、胠，再辨受伤方向之轻重（前面撞打跌仆者重，后面撞仆者轻），末及「先按證用手法治之，再內服正骨紫金丹」等。
→ 部位 → 病机轻重 → 治法，层次井然。

### 案例 4：眼科与刺灸的目录即索引（`S57-P01`、`S58-P01`）
卷七十八目录列「外障總名歌」等（各歌名下附「方附」）；卷七十九目录列「行鍼次第手法歌」等（下注「共十二歌」）。
→ 分科内容以「歌 + 图 + 方附」组织，目录可直接用于定位。

- 与 `anquan-bianjie`：正骨手法、外治、灸法一旦涉及「怎么操作／能不能自己做」，转它。

## E — 可执行步骤（Execution）

1. **定位分科与卷次**
   - 用目录页（如 `S43-P01`、`S57-P01`、`S58-P01`、`S60-P01`）确定卷次与篇名。
   - 完成标准：给出卷次 + `Sxx-Pxx`。

2. **先定部位／经络，再谈证**
   - 按「形色部位 → 经络 → 脏腑气血 → 阴阳虚实 → 六淫七情」顺序引用 `S01-P25`。
   - 完成标准：不以「外科病」为由跳过内因分析。

3. **处理图与分寸**
   - 图只作名目与版式依据；图中小字漫漶未录者明确说明「本次未转录，不可据此定位」。
   - 完成标准：不补写穴位名、不给出具体分寸数值。

4. **应用可信度分级**
   - 涉八廓等臆说，引 `S01-P24` 说明本书「據經訂正、棄其駁雜」的立场。
   - 完成标准：不把被本书剔除的内容当作本书主张。

5. **输出与判停**
   - 四段：分科卷次 / 部位与经络依据 / 图注与体例说明 / 安全提示。
   - 不指导手法操作、不推荐外治执行、不给剂量。

## B — 边界（Boundary）

### 不要在以下情况使用
- 用户要按图自行取穴、施灸、正骨 → 明确说明图中细字未转录且涉及专业操作，转 `anquan-bianjie` 并提示就医。
- 用户要外用药组成剂量 → 只可原文引录，转 `anquan-bianjie` 判停。
- 急症外伤 → 立即提示就医。

### 书中警告的失败模式
- 「八廓則憑臆立論，三因病情未見精切」（`S01-P24`）：采信无据之说。
- 「毫釐一差，千里遂謬」（`S01-P24`）：分寸不精而施针。
- 「亦只言其證藥，而於經絡部位骨度名目手法俱未嘗詳言之」（`S01-P25` 评前代正骨书）：只谈方药不谈部位手法。

### 盲点与时代局限
- 骨度、经络、五轮属 18 世纪解剖与类比体系，不等同现代解剖学。
- 本次转录的 6 幅插图，图中穴位／部位小字均因漫漶**未录**，图谱信息不完整。
- 正骨、灸法、外治手法按今日标准存在风险，不可据文字自行施行。

### 容易混淆的邻近方法论
- 现代针灸穴位定位标准、现代骨科处理流程均不在本书语料内，不得混入。
