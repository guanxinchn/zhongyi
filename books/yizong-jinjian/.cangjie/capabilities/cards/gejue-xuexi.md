# CAP-11 歌诀学习辅导与背诵

> capability_id: CAP-11 ｜ 重要度: medium ｜ 来源: 卷三十四《編輯四診心法要訣》、卷三十六《編輯傷寒心法要訣》、首卷凡例

## R — 原文（Reading）

> 今採醫經論色診之文確然可法者編爲四言合崔嘉彥四言脈訣名曰四診要訣實該望聞問切之道使後之爲醫師者由是而教爲弟子者由是而學熟讀習玩揣摩日久自能洞悉其妙
>
> — 卷三十四《編輯四診心法要訣上》小序，`S25-P02`

> 望以目察聞以耳占問以言審切以指參明斯診道識病根源能合色脈可以萬全
>
> — 卷三十四开篇歌诀，`S25-P03`

> 學者熟讀玩味臨證之時自有得心應手之妙
>
> — 首卷凡例葉二，`S01-P22`

## I — 方法论骨架（Interpretation）

本书把大量内容编成四言／七言歌诀，目的是可记诵、可在临证时即时调用（「熟讀習玩，揣摩日久」「熟讀玩味，臨證之時自有得心應手之妙」）。歌诀不是内容的简化版，而是**记忆编码**：每句背后都有低格注文作展开。

因此学习顺序必须是「口诀 → 注文 → 结构 → 自测」，而不是「白话翻译 → 记忆」。注文才是意义所在；只背歌诀不理解注文，等于记住了索引却没取到内容。

教学时的硬规矩：原文照录（繁体、不改简体、不加标点、不加字），释义另栏标注「非原文」；遇到 `□` 或缺字，如实说明「此处影印漫漶，未转录」，不得猜字补齐后让学生背诵。

## A1 — 书中的应用（Past Application）

### 案例 1：四诊开篇歌诀 + 注文（`S25-P03`）
歌诀四句分列望闻问切；注文逐句引「望而知之爲之神……聞而知之謂之聖……問而知之謂之工……切而知之謂之巧」，末以「互相參合，則可識萬病根源」收束。
→ 四句口诀对应四个概念 + 一条合参原则，是「逐句对注」的样板。

### 案例 2：伤寒传经歌诀 + 注文（`S27-P05`）
歌诀「六經爲病盡傷寒，氣同病異豈期然，推其形藏原非一，因從類化故多端……漫言變化千般狀，不外陰陽表裏間」；注文逐词解释「六經謂……」「氣同爲……」「因從類化故多端謂……」。
→ 注文采用**逐词训释**体例，适合做成填空式自测。

### 案例 3：疟疾总括歌诀 + 注文（`S30-P02`）
「夏傷於暑舍營內，秋感寒風并衛居，比時或為外邪束，暑汗無出病瘧疾」；注文引经文「夏傷於暑，秋為痎瘧」「夏暑汗不出者，秋成風瘧」等逐句作证。
→ 歌诀与经典互证，讲解时须把注文所引经文一并指出。

### 案例 4：编书者自述的教学意图（`S25-P02`、`S01-P22`）
小序「使後之爲醫師者由是而教，爲弟子者由是而學」——歌诀同时是教本与学本，故讲解与自测都是本书原生用法。

## A2 — 触发场景（Future Trigger）

### 情境
1. 用户要学、背、讲解某段歌诀。
2. 用户要辨析易混歌诀或整理记忆脉络。
3. 用户要自测题、填空、默写。
4. 用户问「这段歌诀什么意思」。

### 语言信号
- 「帮我背」「怎么记」「逐句讲解」「这段歌诀」「出自哪卷」「出几道题」
- 「四言脉诀」「心法要诀」「总括歌」
- "memorize", "recite", "explain this verse", "quiz me"

### 与相邻能力的区分
- 与 `zhengwu-cunyi`：歌诀原文照录与出处由它约束；本卡负责教学编排。
- 与 `bazheng-tuigang`：辨析证候走八纲卡，本卡讲歌诀文本。
- 与 `anquan-bianjie`：歌诀中出现方药时，只讲文本，不给剂量与服法建议。

## E — 可执行步骤（Execution）

1. **照录原文**
   - 从 `corpus/` 取歌诀，繁体照录、保留 `□`、不改简体、不加标点；附 `Sxx-Pxx` + 卷次篇名。
   - 完成标准：原文可逐字回查；漫漶处明确标注。

2. **逐句对注文**
   - 把注文按歌诀句次拆开对应；注文引经文处（如 `S30-P02`）一并指出。
   - 完成标准：每句歌诀都有对应解释，解释注明「注文／释义」。

3. **归纳结构**
   - 说明这首歌诀分几层、记忆锚点是什么（如四诊＝神聖工巧＋合参）。
   - 完成标准：给出不超过 5 条的记忆提纲，且每条能回指原文。

4. **设计自测**
   - 出填空、接句、易混辨析三类题；**答案必须能在语料中找到**，不自行编造歌诀。
   - 完成标准：题目不涉及未转录内容。

5. **收尾**
   - 给出处清单与本段在分部中的位置；若用户要求更多段落而语料未覆盖，明确说明未转录。

## B — 边界（Boundary）

### 不要在以下情况使用
- 用户要的是辨证结论或处方 → 转相应能力卡。
- 用户要求「凭记忆补出缺字」→ 明确拒绝，引用 `S02-P03` 存疑之例。
- 用户要求改写成简体顺口溜便于背诵 → 可提供释义，但不得冒充原文。

### 书中警告的失败模式
- 「近世惟事切巧，不事望神」（`S25-P02`）：只取便于记的部分，忽略整体。
- 「不求其精意而徒執其方，是執方而昧法」（`S01-P22`）：只背口诀不求其义。
- 「勉加註釋，終屬牽强」（`S02-P03`）：难解处强行解释。

### 盲点与时代局限
- 歌诀中的名物、病名、药物属 18 世纪口径，讲解时不作现代化等同。
- 「揣摩日久自能洞悉其妙」是断言而非经验验证；本卡不承诺背诵效果。

### 容易混淆的邻近方法论
- 后世改编的《医宗金鉴》歌诀白话本不在语料内，不得混入。
